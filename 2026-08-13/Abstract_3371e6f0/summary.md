# 论文速读：InViStream: Real-Time Privacy-Preserving Volumetric Video Streaming

## 一句话总结
本文提出 InViStream，一种面向 RGB-D 体积视频流的**源端隐私保护**系统，通过轻量检测、深度感知遮罩与跨视角公共/私有实例同步，在云端融合前实时滤除隐私内容，同时保留公共场景的三维重建可用性。

---

## 研究问题与动机

1. **体积视频的隐私是 3D 多视角问题**：传统 2D 视频可对单帧逐帧红 acted，但 RGB-D 体积管线从多个相机捕获人脸、房间和个人物品并融合为共享 3D 表示；任一视角漏掉的隐私内容可能在重建场景中以深度几何形态重现。
2. **现有系统缺乏隐私设计**：当前 VVS 系统仅优化重建数据流量与时延，未考虑隐私；而现有隐私保护视觉方法针对单相机单帧设计，无法处理校准多视角 RGB-D 融合。
3. **同品类歧义性（same-class ambiguity）**：场景中可存在多个"人"实例，其中前景参与者应为公共，背景路人及私人物品需被移除——类级 masking 会一刀切或全部泄露。
4. **源端过滤（privacy-from-source）必要性**：原始 RGB-D 数据一旦离开相机端，后期模糊或访问控制无法撤销初始暴露，隐私保护必须在数据出边端前完成。

---

## 核心贡献（创新点）

1. **形式化体积视频源端隐私问题**：明确定义了校准 RGB-D 体积视频流下的"诚实但好奇云模型"与公共/私有实例级策略需求，填补了体积流隐私的理论空白。
2. **深度感知多视角遮罩管线（InViStream）**：组合自包含检测、深度条件遮罩构建、参考视角公共/私有同步、以及云侧私有点移除，是一个端到端的体积流隐私处理框架。
3. **同类实例级策略（instance-level policy）**：区别于类级 masking，系统可在同一类别（如"人"）内区分公共参与者和私有路人，通过参考视角 + 校准变换跨视角传播公共实例中心实现。
4. **实证基准与运行时权衡分析**：在合成（400+ 配置）与真实（5 环境、150+ 实例）RGB-D 场景上全面评估，揭示了 chunk size、骨干网络、深度阈值之间的隐私/时延/吞吐三方可调权衡。

---

## 方法详解

**整体架构**：边端设备在相机侧运行轻量检测与遮罩，云侧仅接收 sanitized RGB-D 帧并完成点云转换、私有点移除、坐标对齐与融合。

**关键设计模块**：

1. **分块检测（Object detection on chunk starts）**：仅在长度为 N 的帧块首帧运行轻量目标检测器（Faster R-CNN + ResNet-50-FPN 或 MobileNetV3），返回边界框集合 $O_{\nu,t} = \{(b_i, s_i, l_i)\}$，置信度 $s_i \geq \theta$ 且类别 $l_i \in C$ 的框为敏感候选。

2. **深度条件遮罩（Depth-conditioned masks）**：对每个敏感框 $b_i$，计算中心 $(c_x^i, c_y^i)$，提取 $w \times h$ 深度窗口 $V_i$，估计深度分布 $\mu_i, \sigma_i$，阈值 $\tau_i = \alpha \sigma_i$。遮罩定义为：
$$M_i(u,v) = \mathbf{1}\{(u,v) \in b_i\} \cdot \mathbf{1}\{|D_{\nu,t}(u,v) - \mu_i| \leq \tau_i\}$$
边界框项限制泄漏范围，深度项避免粗粒度 box-level 过遮。

3. **跨视角公共/私有同步**：参考视角 $r$ 中用户划定工作区域内的敏感实例标记为公共；对其中心 $(r_x, r_y, r_z)$ 通过校准变换 $\mathbf{T}_{r \to w}$ 投影到目标视角 $w$，最近邻同类别框标为公共，其余同类框标为私有（保守策略）。

4. **点移除与云侧融合**：遮罩后的 RGB-D 帧传至云端，转换为点云，颜色匹配私有遮罩的点被赋为无穷坐标并移除（Open3D non-finite-point filter），再变换到全局坐标系后合并。

5. **时序优化**：块内帧复用已存深度轮廓与边界框，降低检测开销；但块越长运动中的隐私目标可能因深度漂移而召回下降。

## 实验与结果

**数据集**：
- 合成：3 个室内网格场景（Gallery House/Round, Jedi Council），8 个虚拟视角，插入 V-Sense 与 8i 人体模型，共 400+ 场景配置。
- 真实：Intel RealSense D435，5 种环境（会议室、开放式办公室、走廊、户外露台、客厅），8 个校准视角，4 种活动（交谈、行走、坐姿、站姿），150+ 实例，6 名成年人参与者。

**评估指标**：Dice、Recall（隐私侧）、SSIM、Point Distance（效用侧）、PODR（Post-Masking Object Detection Rate，事后检测率）、时延、FPS。

**主要结果**：
- 合成平均：Dice=0.799，Recall=0.891，SSIM>0.98，Point Distance≈2×10⁻⁴
- 真实平均：Dice=0.792，Recall=0.908
- PODR：合成场景从 100% 降至平均 6.3%（范围 1.0%–12.5%）；真实场景降至 14.3%（范围 1.0%–25.0%）
- 实时性能：MobileNet N=5 时遮罩时延 17.4ms，吞吐 57.5 FPS；ResNet-50 N=20 时 41.2 FPS

**最强结果**：真实场景 Recall 达 0.908，会议厅场景 Recall 高达 0.931；合成 SSIM 稳定在 0.989，表明公共场景几何与视觉质量几乎无损。

**基线对比**：InViStream Dice 0.80，接近 SAM（0.85）但时延仅为 90ms vs 1420ms；显著优于轻量 Tiny U-Net（0.56）、EdgeSAM（0.71）、EdgeTAM（0.69）。

## 相关工作脉络

1. **VVS 系统**（MetaStream, Vivo, M5, Habitius, FarFetchFusion, Theia, Immerscope, MagicStream 等）：专注带宽、传输、渲染优化，完全未涉及隐私问题；InViStream 与其正交互补——决定"什么数据可安全发出"。
2. **图像隐私保护视觉方法**（Face/of, Primask, ViewMap, Preva, Shredds, Fawkes, Disco, Pecam, PintO, CamPro 等）：主要针对单相机 2D 帧的转换/混淆/安全推理，未处理同品类歧义与跨视角一致性。
3. **分割模型**（SAM, Tiny U-Net, EdgeSAM, EdgeTAM）：虽可生成精细 mask，但不知晓哪些同类实例应保留——直接应用会导致全删或全漏；且密集逐帧分割在边端设备上时延过高。
4. **定位差异**：现有方法将隐私视为后处理步骤（reconstruction 之后），本文证明必须作为源端 multi-view computer vision 问题在融合前解决。

## 局限性与未来方向

1. **依赖外部条件质量**：检测器精度、深度传感器质量（对反光表面、透明物体、低光照、直射阳光、远距离失效）、相机标定误差均直接影响性能。
2. **同步采集限制**：真实数据集采用顺序静态拍摄而非全硬件同步多相机阵列，未充分测量部署场景中的时间同步误差。
3. **保护范围有限**：仅保护 RGB 外观与深度几何，不覆盖音频、元数据泄漏，以及公共物体上可见的敏感信息（如屏幕内容）。
4. **误用风险（false confidence）**：用户可能误以为所有隐私信息已被清除，而检测/深度/标定故障可能留下残留证据。
5. **未来方向**：探索更鲁棒的深度估计、端到端硬件同步采集基准、与加密/安全推理结合的多层防护、以及自适应 chunk 策略的在线优化。

## 研究启发与可借鉴点

1. **深度条件遮罩设计**：将边界框约束与深度分布约束相乘（公式 3），兼顾定位精度与形状贴合，可迁移至任意需要"精准剔除 3D 物体但不影响邻近区域"的应用。
2. **参考视角公共实例跨视角传播**：通过校准外参将参考视角的"公共"决策投影到其他视角，是解决同类实例歧义的一种优雅低成本方案，可推广至多视角实例级策略一致性任务。
3. **Chunk-based 时序复用策略**：仅在块首帧运行重检测、后续帧复用深度轮廓，在隐私召回与边缘算力之间提供显式可调参数 N，为实时系统的资源管理提供了清晰的设计空间。
4. **多维度评估体系**：同时报告隐私侧（Recall, PODR）与效用侧（SSIM, Point Distance）指标，并引入事后检测率（PODR）作为端到端安全检查，避免单一指标掩盖真实泄漏风险。
5. **部署友好的分层架构**：边端负责隐私决策，云侧仅执行点云处理与融合，使得隐私模块可插拔集成到现有 VVS 管线中，为工程落地提供了可行范式。

## 关键术语表

**Volumetric Video Streaming (VVS)**：将场景表示为时变 3D 内容（点云或网格），支持六自由度远程存在感与混合现实体验的视频传输技术。

**Privacy-from-source**：在原始 RGB-D 数据离开相机端之前即完成隐私过滤，而非在云端或接收端进行事后处理。

**Depth-conditioned Mask**：结合边界框空间约束与深度分布一致性约束生成的像素级遮罩，精确剔除目标而不影响邻近公共区域。

**Same-class Ambiguity**：同一语义类别中存在公共与私有多个实例（如一个参与者+一个路人），需实例级而非类级策略进行区分。

**Public/Private Synchronization**：通过参考视角的公共实例中心，利用校准变换跨视角传播决策，确保多视角一致的公共/私有标记。

**PODR (Private-Object Detection Rate)**：遮罩后使用目标检测器仍能检测到隐私目标的比率，越低表示隐私保护越强。

**Chunk-based Temporal Reuse**：每 N 帧运行一次检测，中间帧复用已有深度轮廓与边界框，以算力换取实时性。

**Honest-but-curious Cloud**：假设云服务器遵守协议但可能 inspect 所接收数据的安全威胁模型，不适用于恶意攻击场景。
