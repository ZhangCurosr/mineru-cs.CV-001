# 论文速读：Predicting-Functions-Not-Features-KANs-with-Function-Space-J

## 一句话总结
提出FS-JEPA（Function-Space Joint-Embedding Predictive Learning）框架，将联合嵌入预测学习从特征空间扩展到KAN预聚合函数空间，通过预测多半径边函数签名实现对边缘函数的显式学习目标，在五个医学图像分割基准上实现最优平均Dice（83.37%），较最强对比方法UUEKAN提升+2.25pp。

## 研究问题与动机
- 现有KAN-based分割模型（如U-KAN、MM-UKAN++）仅通过聚合节点输出的任务目标优化边函数，缺乏对单个边函数的显式预聚合学习目标
- KAN边聚合存在多对一映射：不同边函数配置可能产生相似的节点输出，导致个体函数行为仅被隐式约束
- 单次响应评估无法表征函数局部行为：两个函数在同一输入锚点处可能响应相同，但在邻近点行为显著不同
- 现有JEPA方法局限于图像/token/特征级嵌入，未考虑将可学习神经函数作为预测目标

## 核心贡献（创新点）
1. **首次将JEPA扩展到KAN原生预聚合函数空间**：将预测目标从特征嵌入转向结构化边函数签名，实现了从"预测特征"到"预测函数"的范式转变，区别于现有feature-level JEPA方法
2. **提出多半径函数签名表示**：通过在输入锚点周围六个偏移位置评估边函数捕获局部函数变化，相比单一响应预测提供了信息更丰富的预测目标，本质区别在于从标量响应扩展为结构化函数表征
3. **开发训练专用预测框架并保证确定性边对应**：在线分支预测EMA目标分支生成的签名，通过共享边索引与确定性坐标建立预测-目标显式对应，预测组件在推理时完全移除不影响部署效率
4. **端到端联合优化且无需预训练**：函数空间预测目标与分割任务损失从随机初始化联合优化，无需外部预训练权重或teacher模型，与常见自监督方法依赖预训练的特点形成对比

## 方法详解
**KAN边函数参数化**：
采用基于B样条的边函数表示，第(j,i)条边的响应为：φ_{j,i}(u) = w_{j,i}^b · SiLU(u) + s_{j,i} · Σ_{ℓ=1}^{L} w_{j,i,ℓ}^s · B_ℓ^p(u)，其中包含基础函数系数、样条系数、可学习样条尺度。

**边采样与选中边算子**：
随机采样K对输入-输出边S = {(i_k, j_k)}_{k=1}^{K}，定义选中边算子Φ_S(U)_{b,n,k} = φ_{j_k,i_k}(U_{b,n,i_k})，将辅助激活成本从O(BNd_in d_out)降至O(BNK)。

**多半径函数签名**：
对采样边e = (i,j)与锚点输入u，定义局部偏移集合D = {-0.10, -0.05, -0.025, 0.025, 0.05, 0.10}，签名s_e = [φ_e(u-0.10), φ_e(u-0.05), ..., φ_e(u+0.10)]，构成6维向量捕获函数局部变化模式。

**确定性边对应编码**：
对采样边(i,j)，编码确定性地源-目标节点坐标：p_i = 2(i-1)/(d_in-1) - 1，p_j = 2(j-1)/(d_out-1) - 1，将(p_i, p_j)拼接至签名输入以建立预测-目标的显式对应关系。

**预测学习目标**：
在线分支接收mask后的上下文与边信息，输出ŝ_e = q_ψ(z_e)，EMA目标分支输出s_e^+ = sg( s̄_e^{EMA} )，预测损失为ℒ_sig = SmoothL1(ŝ_e, s_e^+)。

**联合优化**：
总损失ℒ_total = ℒ_seg + λ_deep ℒ_deep + (λ_sig/4) Σ_{b=1}^{4} ℒ_sig^{(b)}，四个配备预测分支的KAN块各自计算签名损失后平均。

## 实验与结果
**数据集**：BUSI（乳腺超声）、DDTI（甲状腺超声）、TN3K（甲状腺结节）、CVC-ClinicDB（结肠息肉）、GlaS（组织病理腺体），共五类医学图像分割基准。

**主要结果**：FS-JEPA平均Dice达83.37%，平均IoU达75.04%，五项基准均取得最优或次优；相对最强KAN基线UUEKAN提升+2.25pp Dice，且参数量仅为35.02M的1/4（本方法7.74M）。

**消融发现**：
- 对比Token-JEPA（0.7808 Dice）和Node-JEPA（0.7845 Dice），边函数空间预测显著优于特征/节点级预测
- Raw multi-point签名在预测诊断指标上最优：Rel. MAE=0.9175、NRMSE=0.8999、Pearson r=0.4622
- 相比Response-only（Edge-JEPA，Dice 0.7771），Raw multi-point提升至0.7926（+1.55%）
- 跨骨干泛化：在U-KAN、UUEKAN、KMUNet三个不同架构上均获得Dice提升，平均+0.47pp

## 相关工作脉络
- **JEPA系列（I-JEPA/MC-JEPA）**：本文方法本质不同——JEPA预测目标为特征嵌入，本文预测目标为KAN可学习边函数的结构化签名，且定义在预聚合函数空间
- **BYOL/VICReg**：无负样本对比学习方法，本文不依赖对比损失或重建损失，而是通过函数空间预测目标直接约束边函数行为
- **U-KAN / MM-UKAN++ / KMUNet / UUEKAN**：均为KAN-based医学分割方法，但它们仅在聚合后节点层面施加任务监督；本文在此基础上引入预聚合边函数预测目标
- **PBE-UNet / Rolling-UNet**：CNN-based高效医学分割方法，本文聚焦KAN架构的表征学习机制改进，两者属于正交研究方向

## 局限性与未来方向
- **随机采样边可能遗漏重要边函数**：当前采用随机采样策略，可能无法覆盖对分割任务最关键的功能性边
- **多半径签名的偏移范围D为固定经验值**：未探索自适应偏移或多尺度半径设计
- **仅验证于医学图像分割**：跨域泛化能力（如自然图像分割、检测、分类）尚未验证
- **推理阶段预测组件完全移除**：无法利用预测不确定性作为辅助信息，限制了模型可靠度估计能力

## 研究启发与可借鉴点
- **可复用的"函数空间预测"思路**：将自监督预测目标从特征空间扩展至可学习算子空间的概念具有普适性，可迁移至Mamba、状态空间模型等新型架构的表征学习
- **确定性边坐标编码机制**：用归一化整数坐标建立采样边对应关系的设计简洁有效，可作为通用"结构性对应保持"技巧应用于其他随机采样场景
- **预测-目标EMA机制在函数空间的适配**：EMA目标分支提供稳定预测目标的设计可与现有JEPA框架无缝集成，无需额外teacher模型
- **可借鉴的实验设计**：通过"Matched Scaffold"对照组隔离预测模块贡献、跨三个不同KAN骨干验证泛化性、多维度预测诊断指标（Rel. MAE/NRMSE/Pearson r）评估表征质量

## 关键术语表
**Kolmogorov–Arnold Networks (KAN)**：将可学习单变量函数放置于网络边上的网络架构，通过B样条基函数显式参数化非线性变换
**Joint-Embedding Predictive Architecture (JEPA)**：通过预测目标表征而非重建输入来学习结构化表示的自监督学习框架
**Exponential Moving Average (EMA) Target Branch**：缓慢更新的预测目标分支，通过指数移动平均累积在线分支的历史状态而不接收梯度
**Multi-radius Function Signature**：在输入锚点周围多个偏移位置评估边函数得到的结构化表征，捕获函数的局部变化模式
**Deterministic Edge Coordinates**：将边的输入/输出节点位置编码为归一化坐标(p_i, p_j)，用于建立预测与目标之间的显式对应关系
**Selected-edge Operator (Φ_S)**：从全部边中随机采样K条边进行高效评估的算子，将计算复杂度从O(N d_in d_out)降至O(NK)
**Matched Scaffold**：与FS-JEPA完全相同的分割骨干网络但不含预测分支的训练对照组
