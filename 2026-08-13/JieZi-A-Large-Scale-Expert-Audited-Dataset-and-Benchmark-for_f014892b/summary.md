# 论文速读：JieZi-A-Large-Scale-Expert-Audited-Dataset-and-Benchmark-for

## 一句话总结
本文首次将古代汉字训诂形式化为四层次渐进式视觉-语言问答任务（ACCE），并构建了首个大规模专家审校训练数据集JieZi-Dataset（约50万QA对、13万字形）和对应评估基准JieZi-Bench（约8千QA对），证明高质量领域数据对古文字理解任务的价值远超模型规模放大。

## 研究问题与动机
1. **任务碎片化**：现有计算工作仅聚焦字符识别、图像检索等窄子任务，未能形式化完整的学者级训诂工作流，无法支持多维度综合分析。
2. **领域知识匮乏与幻觉问题**：当前MLLM缺乏古文字学专业知识，直接应用于古文字分析时频繁产生事实性幻觉；而纯人工标注成本极高、全自动生成又不可靠。
3. **评估基准缺失**：现有VQA基准不含古文字图像，古文字领域仅有的基准（如OBI-Bench）聚焦单一甲骨文字种及考古场景，缺乏覆盖多字种、多分析维度的标准化评估框架。

## 核心贡献（创新点）
1. **首次将古代汉字训诂形式化为ACCE任务**，按传统小学方法论拆分为四个渐进层次（基础信息→字形分析→字义阐释→历时演变），现有工作均只覆盖其中片段。
2. **构建JieZi-Dataset**——首个覆盖六字种（甲骨、金文、战国、篆、隶、楷）的大规模专家审校VQA训练集，通过"专家模板约束+源文本锚定"的LLM生成流水线，以约1000小时人工校对面换取50万可靠QA对，避免了纯自动生成的幻觉风险。
3. **构建JieZi-Bench**——完全由人类专家逐条审核的评估基准，参考答案来源于与训练数据严格隔离的四部权威辞书（《康熙字典》《说文解字》《说文解字注》《现代汉语词典》修订版），从根本上杜绝数据泄露。
4. **系统性基线实验揭示关键洞察**：领域特定数据的作用远大于模型规模；SFT学习的是推理模式而非知识暴露；即使轻量化模型经SFT也能超越参数量大一到两个数量级的通用模型。

## 方法详解
**ACCE四层次任务定义：**
- **L1 基础信息**：CHAR（字符识别，映射到现代标准汉字）和 SCRC（字种分类，识别甲骨/金文/篆/隶/楷等）。
- **L2 字形分析**：包含五个子任务——STRC（结构分类，描述部件空间布局）、COMR（部件识别）、COMF（部件功能，标识表意/表音/符号）、COMI（部件解读，阐释各部件语义）、FORC（造字法分类，依六书体系归为象形/指事/会意/形声等）。
- **L3 字义阐释**：ORIM（原义，解释历史语境下的核心语义）。
- **L4 历时演变**：COME（部件演变，追踪部件跨字种的形态变化）和 EVOI（演变阐释，全局分析字形演变动因）。

**数据构建三阶段流水线：**
1. **收集阶段**：以《汉字源流大字典》（2000余页、500万词元）为主要来源，OCR使用Gemini-2.5-Pro，字形检测使用独立训练的YOLOv11；外部分配数据（ACCP、MegaHan97K）以该字典为锚点筛选一致条目。
2. **结构化阶段**：用Gemini-3-Flash将非结构化字典条目解析为JSON元数据，覆盖L1–L4所有字段；JieZi-Dataset抽检10%，JieZi-Bench全量审核。
3. **VQA生成阶段**：设计基于真实研究场景的QA模板，将已验证元数据作为动态上下文注入LLM生成提示，约束模型"从证据推理而非参数记忆"；每个字形随机生成5–10对QA，确保L1–L4全覆盖。

**质量保障策略**：JieZi-Dataset采用阶段抽查（Stage 2抽检10%记录、Stage 3抽查5K实例，错误率分别约1%和3%）以平衡规模与质量；JieZi-Bench全程全量专家审核（各阶段错误率约5%、10%）。

**训练设置**：在Qwen3.5-2B/4B/9B上进行SFT，学习率1e-5，cosine schedule，warmup ratio 0.05，weight decay 0.1，AdamW，bf16精度，5 epochs；2B/4B max length 2048，9B max length 1024，batch size 128/128/64，硬件为8×Ascend 910B。

## 实验与结果
**数据集规模**：JieZi-Dataset含约13K独特字符、130K字形图像（含12.3%来自真实历史文档的自然退化图像）、500K QA对；JieZi-Bench含1024字形、约8K QA对，其中25%为未见过的（字,字种）组合、12.5%为完全未见过的字符、25.2%的部件未在训练集中出现。

**评估指标**：分类任务用Accuracy，部件识别/功能/演变任务用字符级F1-Score，开放式生成任务（ORIM、COMI）用BERTScore，EVOI用LLM-as-a-Judge（Fact Alignment + Scholarly Expression两维度，经200样本人工验证Pearson>0.60）。

**主要结果（Qwen3.5-9B + JieZi-Dataset SFT）**：在JieZi-Bench上全面领先，CHAR=52.6、SCRC=80.1、COMR=48.1、COME=45.4、EVOI-FAC=32.5、EVOI-SCE=40.6，超越Kimi-K2.5（170B）、GLM-4.6V（107B）、Qwen3.5-397b等更大模型。最小模型Qwen3.5-2B+SFT在COMR和FORC等结构解析任务上已超过GPT-5.4和Gemini-3.1 Pro。

**关键洞察**：
- 中文训练数据丰富的模型（Doubao-Seed-2.0-pro、Kimi-K2.5）显著优于同等规模的西方模型（GPT-5.4 CHAR仅10.4 vs Doubao 36.6），说明领域数据覆盖比模型规模更关键。
- tonggu-vl-2B（古文献专用模型）在多数ACCE子任务上<5%，证明古文献OCR与训诂推理是本质不同的任务。
- 消融实验显示：结构化元数据对分类子任务增益最大（COMF +16.0），VQA重格式化对生成子任务增益最大（COMI +13.0，FAC +10.2），开源数据增强强化视觉鲁棒性（CHAR +6.5）。
- 数据缩放实验显示性能随数据量单调递增（25%→100%宏平均从36.5增至46.8），全部50万数据仍带来边际收益。

**泛化分析**：SFT模型在未见字符上的CHAR接近零，但结构解析指标（COMF、FORC）几乎不下降（如Seal UG的COMF仅51.9→49.8），证明模型学到的是可迁移的文字学知识而非机械记忆；金文和篆书仍是最大挑战（CHAR：楷书82.2→篆书51.5→金文18.3）。

## 相关工作脉络
1. **OBIMD / OracleSage / PD-OBS**：仅覆盖甲骨文字种，部分提供多模态对齐，但缺少金文/篆书/隶书等多阶段数据及完整的训诂维度标注。本文首次覆盖六字种的全链条训诂分析。
2. **OBI-Bench / V-Oracle**：聚焦甲骨文碎片拼合与视觉描述等考古子任务，不涉及跨字种的单字系统性训诂评估。
3. **ACCP / ACCID / OBI Component 20**：提供部件级结构标注，但缺乏语义解释、原义阐释和历时演变维度，无法支持L3/L4任务。
4. **C³-Bench / MCS-Bench / AC-EVAL**：评估古典文献段落级理解，完全不涉及单字视觉输入，与ACCE的视觉-语言交叉定位截然不同。
5. **tonggu-vl**：面向古文献OCR和阅读理解的领域模型，在ACCE上几乎全灭，揭示了"阅读古文字"与"训诂分析古文字"的本质差异，为本文任务定位提供反向支撑。

## 局限性与未来方向
1. **早期字种性能瓶颈**：金文和篆书的视觉变异更大、结构更抽象，模型在这些阶段的性能显著低于隶书/楷书，需更强视觉表征或更多稀缺字种数据。
2. **单一主要数据源**：JieZi-Dataset主要来自《汉字源流大字典》，其学术观点可能存在系统性偏差，尚未融合更多争议性考释来源。
3. **基准规模有限**：JieZi-Bench仅约8千QA对，对模型能力上限的评估可能存在天花板效应。
4. **训练范式单一**：仅采用SFT，未探索DPO、RLHF等偏好优化方法在训诂任务上的潜力。
5. **未来方向**：扩展到出土文献（简牍、帛书）的真实残损图像、融合多源学术争议观点、开发交互式训诂辅助工具、探索自监督预训练与训诂知识的联合学习。

## 研究启发与可借鉴点
1. **"专家模板约束+源文本锚定"的数据生成范式**：用专家设计QA模板规范输出格式和覆盖度，同时将被验证的结构化元数据作为LLM生成的动态上下文，既保留LLM的生成扩展性又约束事实准确性，可有效迁移到其他高事实要求的专业领域数据构建。
2. **训练-测试数据严格隔离策略**：JieZi-Bench使用与训练数据完全不同的辞书来源（《康熙字典》《说文》系 vs 《汉字源流大字典》），并从字符、字种、部件三个维度设计了未见子集，这种多维隔离设计对防止评估泄露具有参考价值。
3. **多策略对比验证学习机制**：通过SFT vs Few-shot ICL vs RAG vs Dictionary-context prompting的系统对比，有力证明了性能增益来自推理模式的习得而非单纯知识暴露，这一实验设计可复用验证其他领域的数据价值。
4. **Paraphrase鲁棒性测试**：通过独立改写的问题版本验证模型是否真正学到能力而非模板匹配，为评估训练效果提供了除常规指标外的额外可信度保证。
5. **四层次渐进式任务分解框架**：将复杂专业推理任务按"识别→结构分析→语义阐释→历时追踪"层次化，既便于分阶段评估又保留了最终的综合输出空间，可迁移至其他领域知识密集型任务。

## 关键术语表
**ACCE（Ancient Chinese Character Exegesis）**：古代汉字训诂的计算化形式，指结合视觉分析、语言考证和历史语境对古文字进行系统性学术解读的任务框架。
**训诂（Exegesis）**：中国传统小学中对文字形、音、义进行考证与解释的学术方法，需跨越多重权威辞书并进行学者观点的综合判断。
**六书（Six Writings）**：传统汉字造字分类体系，包括象形、指事、会意、形声、转注、假借六种造字原理。
**部件（Component）**：构成汉字的基本视觉单位，具有特定的结构位置、功能角色（表意/表音/符号）和语义解释。
**JieZi-Dataset**：本文构建的大规模训诂VQA训练数据集，含130K字形图像和约50万专家审校QA对，覆盖六字种和全部十个ACCE子任务。
**JieZi-Bench**：本文构建的专家全量审核评估基准，含1024字形和约8千QA对，参考答案来自与训练数据隔离的权威辞书。
**LLM-as-a-Judge**：使用大语言模型作为自动评判器，依据Fact Alignment和Scholarly Expression两个维度对开放生成答案评分的评估协议。
**Expert-in-the-Loop**：将人类专家介入嵌入数据生成全流程的质量保障策略，兼顾自动化规模和人工审核准确性。
