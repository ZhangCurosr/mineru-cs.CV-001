# 论文速读：DriveCache: Action-Aware Caching for Driving World Model Inference

## 一句话总结
本文提出了 DriveCache，一种无训练、动作感知的扩散缓存控制器，利用生成前的规划自车运动（平移与旋转）作为场景级缓存容忍度先验，结合精确动态规划与因果漂移校正，在多个驾驶视频生成模型上实现了更优的保真度-效率权衡。

## 研究问题与动机
- 驾驶视频生成模型（如 Wan2.2、Epona）在去噪过程中需反复评估大型骨干网络，推理延迟成为在线预测与离线生成的瓶颈。
- 现有扩散加速中的缓存方法（TeaCache、EasyCache、MagCache 等）依赖固定调度或去噪后观测到的信号，**未利用生成前已知的驾驶信号**（如自车速度、规划轨迹），无法感知不同驾驶运动对应的场景视角变化差异。
- 实证表明：缓存容忍度随自车平移/旋转量、去噪进度和连续复用长度而变化，通用方法的缓存策略对这些场景依赖性不敏感。
- 规划自车运动虽可作为缓存先验，但单靠自身不足以确定最优调度——还需结合去噪位置的响应建模与运行时漂移校正机制。

## 核心贡献（创新点）
1. **首次识别并利用规划自车运动作为扩散缓存预生成信号**：证明自车平移与旋转可预测不同驾驶运动下的场景级缓存容忍度，而现有缓存方法忽略了这一先于去噪可用的信号。
2. **提出 DriveCache 无训练缓存控制器**：用两个自车运动锚点（低运动锚点 + 运动转向锚点）校准连续复用的联合响应，并通过精确动态规划在给定响应预算下联合优化复用数量与跨步放置位置，区别于依赖固定规则或后验信号的通用缓存方案。
3. **引入因果漂移检查与后缀重规划机制**：在每次复用前测量输入漂移，当生成偏离校准时拒绝缓存决策并刷新缓存，仅对未执行的后缀重新规划，而保留已执行前缀不变；该机制确保了训练-free 下的运行时鲁棒性，区别于静态调度或全量重规划的方案。

## 方法详解

**框架概述**：将冻结的视频扩散模型的骨干网络输出分离为可复用部分 $r_k = F_k(u_k)$ 与轻量接口 $\epsilon_k = H_k(x_k, r_k)$，控制器在每个骨干评估前观测 $u_k$ 并决定是否复用历史 $r_j$。

**阶段一：规划自车运动校准运行成本**
- 计算场景总平移 $L_s = \sum_t \|p_t - p_{t-1}\|_2$ 与累积旋转 $\Theta_s = \sum_t |\mathrm{wrap}(\psi_t - \psi_{t-1})|$。
- 选取两个锚点：低运动锚点 $(L_0, \Theta_0)$（最小标准化值之和）和运动转向锚点 $(L_1, \Theta_1)$（满足条件的最大标准化值乘积）。
- 对场景进行归一化坐标映射：$z_s^L, z_s^\Theta \in [0,1]$，超出此范围则回退全推理。
- 合并为单一插值坐标 $D_s = \frac{1}{\sqrt{2}}\sqrt{(z_s^L)^2 + (z_s^\Theta)^2}$，用于插值联合响应。

**阶段二：联合响应建模**
- 对每个锚点 $i$，在全去噪轨迹上记录 $(x_k^{(i)}, u_k^{(i)}, r_k^{(i)})$，度量第 $\ell$ 次复用时骨干输入的漂移：$d_{j,\ell}^{(i)} = \|u_{j+\ell}^{(i)} - u_j^{(i)}\|_2 / (\|u_{j+\ell}^{(i)}\|_2 + \varepsilon)$。
- 定义有符号输出扰动：$e_{j,\ell}^{(i)} = H_{j+\ell}(x_{j+\ell}^{(i)}, r_j^{(i)}) - H_{j+\ell}(x_{j+\ell}^{(i)}, r_{j+\ell}^{(i)})$。
- 通过冻结采样器的 Jacobian 向量积将扰动传播到终端潜在：$G_{j,h}^{(i)} = \sum_\ell P_{j+\ell}^{(i)} e_{j+\ell}^{(i)}$，归一化后得联合响应 $q_{j,h}^{(i)}$。
- 场景插值（单边）：$\widetilde{q}_{s,j,h} = q_{j,h}^{(0)} + D_s \cdot \max(q_{j,h}^{(1)} - q_{j,h}^{(0)}, 0)$。
- 构建单调包络 $Q_{s,j,h}$ 与增量成本 $\widehat{c}_{s,j,h} = Q_{s,j,h} - Q_{s,j,h-1}$。

**阶段三：精确动态规划调度**
- 状态 $J_k(n, h)$：k 步后完成 n 次复用、缓存年龄为 h 的最小累积响应。
- 转移方程：全评估重置缓存年龄（$h \to 0$）；复用需满足合法性约束 $\mathcal{L}(k,h)=1$，累加增量成本。
- 在响应预算 $\tau$ 下最大化复用数 $B_s^* = \max\{n : \min_h J_K(n,h) \leq \tau\}$，回溯得最优调度。复杂度 $O(K^3)$ 时间，$O(K^2)$ 滚动内存。

**阶段四：因果漂移检查与后缀重规划**
- 复用前实测漂移 $d_{j,h}^{\mathrm{obs}}$，若 $d_{j,h}^{\mathrm{obs}} \leq \bar{d}_{s,j,h} + \varepsilon$ 且累计成本不超预算则接受；否则强制全评估并刷新缓存，对剩余后缀在预算 $\tau - C_k$ 下重新规划 DP，已执行前缀不变。

**模型特异性适配**：Wan2.2 分离引导分支；A14B 禁止跨专家复用；Epona 仅在每 100 步视觉去噪内复用，不跨自回归段。校准仅需 2 条完整锚点轨迹，分别在 H20 上耗时 4–16 分钟，DP 初始求解 0.8–9.2 ms，漂移检查增加不到 0.7% 端到端延迟。

## 实验与结果

**数据集**：DrivingGen（222 场景 × 10 seed = 2,220 样本）用于 Wan2.2；nuScenes val（150 场景）用于 Epona。校准使用 32 个独立场景。

**评估基线**：DeepCache、PAB、TeaCache、EasyCache、MagCache、DiCache、TaylorSeer、SeaCache、FasterCache、AdaCache、FlowCache、Reduced steps 等。

**指标**：PSNR、SSIM、LPIPS、Traj.（轨迹质量）、ADE（平均位移误差）、DTW、VBench（V-Q、V-S）。

**主要结果**：
- **Wan2.2 5B**：DriveCache 达 1.84× 加速、PSNR 34.744 dB，优于 TeaCache（+2.036 dB PSNR）、SeaCache（+1.884 dB，95% CI: 1.61–2.15）。
- **Wan2.2 A14B**：1.97× 加速、PSNR 32.778 dB，显著优于 SeaCache（+1.276 dB，95% CI: 1.04–1.51）。
- **Epona**：1.89× 加速、LPIPS 0.140，优于 DeepCache（1.68×）在 aggregate 和转向保真度上。
- 运动适应：锚点覆盖 96.4% 场景；静止片段平均复用 22.4 次 vs 转弯 18.7 次。
- 鲁棒性：1.0m/5° 姿态噪声下保持 1.57× 加速，仅损失 0.213 dB。
- 消融（Table 3）：移除运动先验降 PSNR 至 34.201，移除 DP 固定放置降至 33.982，移除漂移否决降至 34.512。

## 相关工作脉络

1. **DeepCache / PAB / FORA**：静态缓存调度，使用固定间隔或学习调度，不利用生成前的驾驶信号，对场景/运动模式不敏感。
2. **TeaCache / AdaCache / EasyCache**：运行时自适应缓存，依赖去噪过程中的后验信号（如时间步嵌入、残差幅度），未利用规划轨迹等先验信息。
3. **MagCache / DiCache / SeaCache**：利用幅度、重构误差或谱演化信号做缓存决策，仍属通用方法，缺乏驾驶运动语义。
4. **FasterCache / TaylorSeer / FlowCache**：分别复用残差、泰勒预测特征、支持自回归视频，与本文方案正交，但同样不涉及规划动作先验。
5. **驾驶视频生成模型（Wan2.2、Epona、DrivingGen）**：本文目标应用平台，这些模型提供规划自车运动作为条件输入，是 DriveCache 可利用的先验来源。
6. **训练型加速方法（蒸馏、量化、剪枝）**：需修改权重或重新训练，而 DriveCache 完全无训练，保持预训练权重和采样步数不变。

## 局限性与未来方向

- **锚点覆盖率非 100%**：96.4% 的场景被锚点覆盖，超出范围的场景回退全推理，极端运动场景可能遗漏。
- **联合响应依赖冻结 Jacobian 近似**：一阶线性传播忽略高阶项，在大幅漂移时可能低估实际误差。
- **仅针对扩散去噪缓存**：未扩展到自回归视频生成中的跨段复用场景（Epona 仅支持段内复用）。
- **校准数据需求**：需 32 个独立场景进行校准，虽仅需一次且耗时短，但在数据稀缺场景下可能受限。
- **运动类型有限**：当前仅考虑平移和旋转，未处理加速度/加加速度等更细粒度的运动表征。
- 未来方向可包括：扩展到自回归跨段复用、引入学习型误差估计器、支持更多驾驶动作类型、向实时在线推理部署推进。

## 研究启发与可借鉴点

1. **先验信号利用范式**：将生成前已知的外部信号（规划轨迹）引入缓存决策，为其他条件生成任务（如文本到视频、机器人操作）提供了"利用条件先验指导计算分配"的可迁移思路。
2. **双边锚点校准设计**：用两个极值锚点（最小/最大容忍度）线性插值中间场景，避免为每个场景单独拟合参数，设计简洁且无需优化器，可在资源受限场景直接复用。
3. **因果漂移检查 + 后缀重规划**：只修正偏离部分而不影响已执行前缀，这一"局部修复"策略比全局重算更高效，可推广至其他需要运行时容错的迭代生成任务。
4. **联合响应的 Jacobian 传播思路**：用冻结采样器的 Jacobian-向量积将局部扰动传播到终端，将步间缓存误差累积为一个标量响应值，为多步决策问题提供了无训练误差估计工具。
5. **动态规划与合法性约束结合**：将模型特异性约束（专家边界、段内复用等）编码入 DP 的状态转移，使同一调度框架可适配不同架构，对多样化部署具有参考价值。

## 关键术语表

**DriveCache**：一种无训练的动作感知扩散缓存控制器，利用规划自车运动分配场景级复用预算，通过动态规划和漂移校正放置复用决策。

**Joint Run Response（联合响应）**：通过冻结采样器的 Jacobian 向量积将连续缓存复用的局部输出扰动传播到终端潜在量，归一化后得到的标量误差度量。

**Planned Ego Motion（规划自车运动）**：生成前已知的自车未来位姿序列，包括平移和旋转，用作场景级缓存容忍度的预生成信号。

**Causal Drift Check（因果漂移检查）**：在每次复用决策前实测输入漂移，超出阈值则拒绝缓存、强制全评估并刷新缓存，同时只重规划未执行后缀。

**Anchor（锚点）**：校准阶段的极端参考场景，包括低运动锚点（最小平移+旋转）和运动转向锚点（最大平移+旋转），用于线性插值中间场景的响应。

**Dynamic Programming Scheduling（动态规划调度）**：在响应预算约束下，以 O(K³) 时间精确优化复用数量和跨步放置位置的最优子结构搜索。

**VBench**：全面的视频生成模型评测基准套件，提供质量（V-Q）和语义（V-S）等多维度指标。

**DrivingGen**：面向自动驾驶的生成视频世界模型综合评测基准，包含 222 个场景和轨迹质量、ADE、DTW 等驾驶相关指标。
