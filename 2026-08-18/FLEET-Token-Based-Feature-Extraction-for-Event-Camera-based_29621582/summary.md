# 论文速读：FLEET-Token-Based-Feature-Extraction-for-Event-Camera-based

## 一句话总结
论文提出了 FLEET，一种面向事件相机强化学习的 Token 化特征提取器，通过随机傅里叶特征与交叉注意力机制直接处理异步事件序列，解决了传统 CNN 网格聚合带来的时空信息模糊与计算冗余问题。

## 研究问题与动机
1. **计算复杂度与分辨率耦合**：现有 CNN 方法将事件聚合成稀疏张量，计算成本随传感器分辨率二次方增长，而实际信息内容稀疏，造成算力浪费。
2. **时间信息模糊**：在标准控制频率下，时间聚合引入了运动模糊，破坏了事件相机高时间分辨率的优势；在高频下则产生大量计算浪费的稀疏张量。
3. **目标函数不匹配（Objective Misalignment）**：基于 VAE 等生成式预训练方法依赖于辅助重建损失，优先优化视觉保真度而非控制相关的特征，导致表征与强化学习目标脱节。
4. **分布偏移（Distribution Shift）风险**：离线预训练的生成式模型若未覆盖部署时的动态范围，在主动学习阶段极易遭遇严重的分布偏移。

## 核心贡献（创新点）
1. **分辨率解耦的特征提取器**：采用 Perceiver 风格的交叉注意力机制，将变长事件序列映射到固定大小的潜在 Token，使后续处理的计算复杂度与传感器分辨率解耦。
2. **任务对齐的表征学习**：完全摒弃辅助重建损失，仅通过强化学习奖励信号进行端到端训练，确保模型专注于学习对控制决策真正有效的动态特征。
3. **频谱偏差缓解**：利用随机傅里叶特征（RFF）嵌入时空坐标，克服了标准 MLP 难以拟合高频细节的频谱偏差，保留了细小的障碍物和快速场景动态。
4. **高频鲁棒的性能验证**：构建了高吞吐量的 Event-CarEnv 基准，证明该方法在提高观测频率时比基于帧的方法具有更强的鲁棒性，且在 Racing 场景中 IQM 显著超越所有基线。

## 方法详解
1. **事件序列采样与批处理**：将原始事件流 $\mathcal{E}_{\tau}$ 划分为 $M$ 个等长子区间，从每个子区间随机采样一个事件（若无足够事件则零填充），形成固定长度序列 $\mathcal{E}_{\mathrm{batched}}$，保留了异步特性。
2. **随机傅里叶特征编码（RFF）**：将时空坐标归一化后，通过公式 $\mathrm{RFF}(\mathbf{x}) = [\sin(\pi \mathbf{x} B), \cos(\pi \mathbf{x} B)]$ 映射到高维空间，其中 $B$ 服从高斯分布。分别对时间和空间分量使用不同的缩放参数 $\sigma$，以捕捉不同频率的细节。
3. **时间门控机制（Temporal Gating）**：通过公式 $\mathbf{z}_{k} = \mathrm{RFF}(\mathbf{u}_{k}) \otimes \mathrm{sigmoid}(W_{\mathrm{gate}} \mathrm{RFF}(t_{k}) + \mathbf{b}_{\mathrm{gate}})$ 融合时空信息，用时间分量生成的调制向量对空间嵌入进行门控，有效捕捉时空动态。
4. **交叉注意力压缩（Cross-Attention Condensation）**：使用 $N$ 个可学习的潜在向量作为 Query，事件嵌入序列作为 Key 和 Value，通过多头交叉注意力将变长序列压缩为 $N$ 个固定大小的 Token，实现了计算负载与输入长度的解耦。
5. **MLP 编码器与全局平均池化**：压缩后的 Token 经过三层 MLP 编码提取全局场景上下文，并通过全局平均池化生成最终的连续特征向量，输入到 PPO 代理中。
6. **停止梯度策略**：Actor 和 Critic 共享特征提取器，但对 Actor 的输入应用停止梯度操作，仅通过 Critic 的价值函数损失更新特征提取器，避免了目标冲突并稳定训练。

## 实验与结果
1. **数据集与环境**：在开源的 CarEnv 模拟器基础上扩展了事件相机仿真，构建了 **Event-CarEnv**（包含 Racing 和 Parking 场景）以及 **Event Inverted Double Pendulum** 测试环境。
2. **评估基线**：包括 Dense RGB CNN (NatureCNN)、Grid-based CNNs (NatureCNN, ImpalaCNN, DMRCNN)、Set-based 方法 (LFF-DS) 以及生成式预训练方法 (eVAE)。
3. **主要结果（Racing 场景）**：FLEET 的 IQM 回报达到 **46.96**，比最强的 CNN 基线 DMRCNN (12.94) 高出约 **263%**，甚至比 Dense RGB CNN (23.89) 高出约 **50%**。
4. **主要结果（Parking 场景）**：FLEET 达到 **5.67** 的 IQM，优于所有其他方法（ImpalaCNN 为 5.18，NatureCNN 为 3.89）。
5. **主要结果（倒立摆任务）**：FLEET 达到 **6390.41** 的 IQM，显著超越所有事件基线，但未超过静态视角下的 Dense RGB CNN (8980.69)。
6. **频率鲁棒性**：在 Racing 场景中，随着控制频率提高（$\Delta t$ 从 0.1 降至 0.025），CNN 方法性能大幅下降，而 FLEET 始终保持高水平（IQM 维持在 41.92 以上）。
7. **分辨率不变性**：当空间分辨率从 96x64 提升至 384x256 时，FLEET 的性能几乎保持不变（IQM 从 46.96 降至 44.32），而 CNN 方法因计算量激增导致显存和推理时间呈二次方增长。

## 相关工作脉络
1. **与 eVAE (Vemprala et al.) 的区别**：eVAE 依赖手动收集轨迹数据进行 VAE 预训练，存在目标不匹配和分布偏移问题；FLEET 无需预训练，端到端直接针对控制任务优化。
2. **与 DMRCNN (Xu et al.) 的区别**：DMRCNN 结合了对比损失和辅助状态预测任务；FLEET 完全不使用任何辅助损失，仅通过 RL 奖励信号学习。
3. **与 LFF-DS (Schier et al.) 的区别**：LFF-DS 基于集合理论处理事件，缺乏对时空结构的精细建模；FLEET 引入交叉注意力机制，更好地捕捉了事件间的长期依赖和空间关系。
4. **与事件变换器 (Event Transformer, Sabater et al.) 的区别**：后者用于监督学习任务且输入为聚合后的事件张量；FLEET 专为 RL 设计，直接处理原始事件序列并解耦计算复杂度。
5. **与基于 SNN 的方法的区别**：SNN 训练困难且常需专用神经形态硬件；FLEET 采用标准的注意力机制和 MLP，兼容主流深度学习框架和硬件。

## 局限性与未来方向
1. **实时采样效率**：当前对变长序列的采样和批处理可能仍存在优化空间，未来可探索更智能的事件采样和过滤技术以进一步降低原始序列长度。
2. **Sim-to-Real 鸿沟**：实验主要在仿真环境进行，未涉及真实世界事件相机的部署，实际硬件噪声、非理想特性及域适应是未来的关键挑战。
3. **超参数敏感性**：潜在 Token 数量 $N$ 和序列长度 $M$ 对性能有一定影响，过小导致信息丢失，过大增加方差，需针对特定任务仔细调优。
4. **极性信息的作用**：消融实验显示移除极性嵌入仍有性能下降但非致命，说明时空动态主导，但极性信息的深度融合方式有待探索。

## 研究启发与可借鉴点
1. **Perceiver 架构在 RL 中的应用**：将交叉注意力用于将变长传感器数据压缩为固定 Token，为处理其他异步传感器（如触觉、雷达点云）提供了可复用的范式。
2. **随机傅里叶特征的坐标嵌入**：在 RL 视觉输入中使用 RFF 代替简单的线性投影或位置编码，能更好地保留高频空间细节，适用于任何需要处理坐标信息的感知任务。
3. **停止梯度训练策略**：在共享特征提取器的 Actor-Critic 架构中，对 Actor 路径应用停止梯度仅由 Critic 更新 backbone，是一种稳定训练的有效技巧。
4. **频率鲁棒性评估**：在不同控制频率（$\Delta t$）下进行系统评估，能揭示模型对时间分辨率变化的适应能力，这是评估事件相机 RL 系统的重要维度。
5. **任务对齐的无监督学习**：证明了在 RL 中完全摒弃重建损失、仅依赖奖励信号进行表征学习是可行且有效的，避免了生成模型中的目标函数错位。

## 关键术语表
**Event Camera**：一种生物视觉启发的传感器，异步记录每个像素的亮度变化，具有毫秒级延迟和高动态范围。
**Random Fourier Features (RFF)**：一种将低维输入映射到高维非线性空间的技术，常用于缓解神经网络的频谱偏差，学习高频函数。
**Cross-Attention**：注意力机制的一种，Query 来自一组可学习参数，Key 和 Value 来自输入序列，用于将变长输入压缩为固定长度的表示。
**Spectral Bias**：神经网络倾向于先学习低频函数而后学习高频函数的现象，可能导致细节信息的丢失。
**Racing/Parking Scenario**：Event-CarEnv 中的两个自动驾驶控制任务，分别要求车辆高速避障行驶和安全泊车。
**Interquartile Mean (IQM)**：一种统计指标，计算数据的四分位距内的平均值，用于评估强化学习算法性能的稳健性。
