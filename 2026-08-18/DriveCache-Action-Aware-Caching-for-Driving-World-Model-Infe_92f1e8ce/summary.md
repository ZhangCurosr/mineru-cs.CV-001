# 论文速读：DriveCache: Action-Aware Caching for Driving World Model Inference

## 一句话总结
本文提出 DriveCache，一种**免训练的动作感知缓存控制器**，首次将规划中的自车运动（平移与旋转）作为扩散模型去噪前的预生成信号，用于场景级缓存预算分配；结合精确动态规划与因果漂移检查，在多个驾驶视频生成器上实现了优于现有缓存基线的**保真度–效率权衡**。

## 研究问题与动机
- 基于扩散的驾驶视频生成模型需在多个去噪步中重复评估大型骨干网络，推理延迟限制了在线预测与离线数据生成的可扩展性。
- 现有免训练扩散加速方法（如 TeaCache、AdaCache 等）依赖固定调度或在去噪开始后观测到的信号，**忽略了驾驶生成特有的预生成先验**——自车速度规划与预期轨迹。
- 不同驾驶动作（静止、直线、转弯）引起的视角变化幅度不同，导致缓存容忍度存在显著的场景依赖性，通用缓存策略无法充分利用这一先验。
- 仅凭规划运动无法确定最优缓存调度，还需结合去噪位置、缓存年龄等因素进行联合建模与因果修正。

## 核心贡献（创新点）
1. **首次识别并验证规划自车运动作为扩散缓存预生成信号**：通过实验证明自车平移与旋转可预测不同驾驶动作下的场景级缓存容忍度，而现有通用缓存方法未利用此类先验。
2. **提出 DriveCache 免训练缓存控制器**：通过两个锚点轨迹校准联合运行响应，利用精确动态规划在响应预算下联合优化复用数量与位置，并与已有工作（如静态调度 DeepCache、运行时自适应 TeaCache）形成本质区别。
3. **引入因果漂移检查机制**：在每次计划复用时测量输入漂移，当生成偏离校准时拒绝复用并重新规划剩余后缀，保证调度因果一致性。
4. **跨多种生成器配置实现一致的保真度–效率提升**：在 Wan2.2 5B（~2× 加速，PSNR 较 TeaCache 提升 2.036 dB）、Wan2.2 A14B 和 Epona 上均优于缓存基线，且无需修改生成器权重或采样步数。

## 方法详解

**问题建模**：将冻结的视频扩散模型的去噪过程分解为可复用的骨干网络 $F_k$ 与轻量级输出接口 $H_k$（式 1），每步 $k$ 决策是否复用最近的 $r_k$ 而非重算 $F_k$。

**场景级预算分配——规划自车运动校准**：
- 从生成时间域的规划自车姿态 $(p_t, \psi_t)$ 计算总平移 $L_s$ 与累积旋转 $\Theta_s$（式 2）。
- 通过**低运动锚点** $(L_0, \Theta_0)$（最小标准化值之和）与**运动转弯锚点** $(L_1, \Theta_1)$（最大标准化乘积）构建支撑区间，通过 z-score 归一化得到场景相对坐标 $(z_s^L, z_s^\Theta)$（式 3）。
- 将二维坐标压缩为单插值变量 $D_s$（式 4），用于场景间的一边插值（仅非负差值参与），避免不支持维度被径向压缩掩盖。

**步级调度——联合响应建模**：
- 对每个锚点 $i$，存储完整去噪轨迹，定义候选复用时段的输入漂移 $d_{j,\ell}^{(i)}$（式 5）与输出扰动 $e_{j,\ell}^{(i)}$（式 6）。
- 通过冻结采样器的 Jacobian-向量积将每一步扰动传播至终端潜变量，得到联合运行响应 $q_{j,h}^{(i)}$（式 7–8），衡量连续复用对终端结果的累积影响。
- 通过单调包络 $Q_{s,j,h}$ 和增量成本 $\widehat{c}_{s,j,h}$（式 9）将响应转化为非负递增代价。

**精确动态规划调度**：
- 状态 $J_k(n, h)$ 表示 $k$ 步后完成 $n$ 次复用、缓存年龄为 $h$ 的最小累积响应（式 10）。
- 在响应预算 $\tau$ 下，最大化可行复用次数 $B_s^*$（式 11），通过回溯恢复最优调度，复杂度 $O(K^3)$ 时间 / $O(K^2)$ 滚动内存。
- **因果漂移检查**（式 12）：在每次计划复用前测量观测漂移 $d^{\mathrm{obs}}$，若超阈值或超出预算则强制执行完整评估、刷新缓存并从年龄 0 重新规划剩余后缀。

**模型特异性合法性约束**：Wan2.2 分离引导分支；A14B 禁止跨专家复用；Epona 仅在每个 100 步视觉去噪调用内复用，跨自回归段不共享。

## 实验与结果

**数据集与基线**：
- **Wan2.2 5B/A14B**：222 个 DrivingGen 场景，10 个固定种子（2,220 样本），40 步去噪。
- **Epona**：150 个 nuScenes 验证场景，100 步视觉去噪调用。
- 基线覆盖固定间隔、PAB、TeaCache、EasyCache、MagCache、DiCache、TaylorSeer、SeaCache、DeepCache、FasterCache、AdaCache、FlowCache 等。
- 评估指标：PSNR、SSIM、LPIPS、Traj.、ADE、DTW、VBench（V-Q、V-S）。

**主要结果（Wan2.2 5B，Table 1）**：
- DriveCache 实现 **1.84× 加速**，PSNR = **34.744 dB**，显著优于 TeaCache（+2.036 dB，95% CI: 1.61–2.15）和 SeaCache（+1.884 dB，95% CI: 1.61–2.15）。
- 轨迹质量（Traj. 0.294）和 DTW（14.768）均为最优。

**主要结果（Wan2.2 A14B，Table 1）**：
- 同样约 **2× 加速**（1.97×），PSNR = **32.778 dB**，较 TeaCache 提升 **1.276 dB**（95% CI: 1.04–1.51），Traj. 0.370、DTW 13.750 最优。

**主要结果（Epona，Table 2）**：
- **1.89× 加速**，PSNR = 26.394 dB，LPIPS = 0.140，速度超过 DeepCache（1.68×）。

**鲁棒性**：在 ±1.0m/±5° 姿态噪声下，仍保持 1.57× 加速与仅 0.213 dB PSNR 损失。

**消融实验（Table 3）**：移除运动先验（-0.543 dB）、打乱轨迹（-0.458 dB）、移除 DP（-0.762 dB）、移除漂移检查（-0.232 dB）均导致质量下降；平移与旋转分量各自贡献显著。

**A14B 专家路由（Table 4）**：将复用从低噪声专家移至高噪声专家导致 PSNR 从 32.778 骤降至 29.936，说明专家边界约束至关重要。

**校准效率**：5B/ A14B/Epona 校准耗时分别为 4/9/16 分钟（单 H20），响应表 <2 MB，初始 DP 求解 <9.2 ms，漂移检查增加端到端延迟 <0.7%。

## 相关工作脉络
1. **TeaCache / AdaCache / EasyCache**：运行时自适应缓存方法，依赖去噪过程中观测到的信号（如 timesteps embedding、响应幅值），未利用驾驶生成特有的预生成规划信息，是本文直接对比的基线。
2. **DeepCache / PAB / FORA**：静态调度缓存，使用固定复用间隔或层优先级，无法适应不同场景的运动特性差异。
3. **MagCache / DiCache / SeaCache**：分别利用幅值、重建误差、谱演化信号进行缓存决策，属于内容感知的后验信号驱动方法，与本文的预生成运动先验形成互补视角。
4. **FasterCache / TaylorSeer / FlowCache**：分别复用残差、用 Taylor 展开预测特征、支持自回归视频，在方法设计上与本文的 DP 调度框架不同，可在同一加速流水线中组合使用。
5. **Learning-to-Cache / OmniCache**：学习型缓存调度，需额外训练预测器；DriveCache 完全免训练，通过两锚点校准实现零参数调度。
6. **Epona / DrivingGen / Vista**：驾驶世界模型生成器；本文在多个不同架构的生成器上验证泛化性，而非针对单一模型设计。

## 局限性与未来方向
- **锚点数量限制**：当前使用 2 个锚点，扩展至更多锚点（2–8 个）仅带来 0.062 dB 变化，说明精度存在上限，难以精细刻画复杂运动模式。
- **仅适用于具有规划自车运动的场景**：对于无明确规划先验的文本驱动或无条件生成任务，该运动先验无法直接应用。
- **校准依赖离线采样**：虽然校准仅需 4–16 分钟且无优化器，但每款新模型仍需重新执行校准流程，尚未实现完全零校准。
- **A14B 跨专家复用受限**：专家边界约束导致复用策略在高噪声专家区域极为保守，未来可探索跨专家的特征共享机制。
- **长期缓存退化问题**：缓存年龄增大时联合响应的线性 Jacobian 近似可能失效，更精确的高阶修正有待研究。

## 研究启发与可借鉴点
1. **预生成信号利用范式**：将任务特有的预生成先验（如规划轨迹、自车速度）引入免训练加速框架，可扩展至机器人操控、视频预测等具有类似先验的信号领域。
2. **双锚点校准策略**：仅需两个极端场景（最小/最大运动）的完整去噪轨迹即可完成模型级校准，大幅降低校准成本，相比学习型方法（需大量标注数据）具有显著优势。
3. **联合响应传播 + 单调包络**：通过 Jacobian-向量积将缓存扰动传播至终端状态，并用单调包络保证非负代价，这一思想可迁移至其他需要时序累积误差估计的任务。
4. **因果漂移检查 + 后缀重规划**：在保持已执行前缀不变的前提下仅对未执行后缀重新规划，保证调度的因果一致性，可作为安全关键系统中"可修正调度"的设计模板。
5. **DP 调度框架的可组合性**：精确动态规划框架可与 FasterCache/TaylorSeer 等方法组合，未来可在同一调度器中嵌入多种缓存原语。

## 关键术语表
- **DriveCache**：本文提出的免训练动作感知缓存控制器，利用规划自车运动分配场景级复用预算，并通过 DP 调度与漂移检查放置复用步。
- **联合运行响应（Joint Run Response）**：通过冻结采样器 Jacobian-向量积将连续复用的多步输出扰动传播至终端潜变量的累积度量。
- **漂移检查（Drift Check）**：在每次计划复用前测量当前骨干输入与刷新时刻输入的归一化 L2 漂移，超阈值则拒绝复用并触发重规划。
- **规划自车运动（Planned Ego Motion）**：生成前已知的自车位移与朝向变化，用于预测不同场景的缓存容忍度。
- **动态规划调度（Exact DP Scheduling）**：在响应预算约束下，以 $O(K^3)$ 时间精确求解最优复用数量与位置的调度算法。
- **一边插值（One-sided Interpolation）**：仅用非负差值对低运动锚点与运动转弯锚点的响应进行插值，保证单调风险关系。
- **Anchor Trace（锚点轨迹）**：在低运动与运动转弯极端场景下执行的完整去噪轨迹，用于校准所有候选复用运行。
- **VBench**：视频生成模型的综合评测基准，包含质量（V-Q）与语义（V-S）等多维度指标。
