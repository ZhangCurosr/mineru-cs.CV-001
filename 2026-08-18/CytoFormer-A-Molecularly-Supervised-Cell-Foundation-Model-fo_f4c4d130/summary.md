# 论文速读：CytoFormer-A-Molecularly-Supervised-Cell-Foundation-Model-fo

## 一句话总结
本文提出了 CytoFormer，一个利用配对空间转录组学（Xenium）自动为 H&E 病理图像中的细胞生成分子标签、从而在无需人工病理标注的情况下训练的细胞级基础模型，在跨 16 个器官的空间留出质控集与四个公开专家标注基准上均显著优于现有主流病理基础模型，并展现出极高的低标注预算主动学习效率。

## 研究问题与动机
- **核心问题**：如何从常规 H&E 组织病理学图像中自动、准确地对单细胞进行类型分类。
- **人工标注瓶颈**：传统细胞分类资源依赖病理学家手动勾画标注，速度慢、成本高，且对形态高度相似的细胞（如巨噬细胞、成纤维细胞、低分化肿瘤细胞）标注可靠性低，现有公共数据集规模仅约 $10^5$ 量级且类别定义互不一致。
- **现有基础模型局限**：UNI2、Virchow2、MUSK 等病理基础模型主要在图块或全切片级别预训练，其监督信号偏向组织/疾病级特征，未能充分捕捉细胞级形态细节，直接复用于单细胞分类仍无法突破标注瓶颈。
- **分子监督动机**：空间转录组学平台（如 Xenium）可在同一张组织切片上同步获得单个细胞的原位表达谱与 H&E 形态，分子身份可作为形态的自动监督信号，实现大规模、低噪声、跨器官的细胞标签生成。

## 核心贡献（创新点）
1. **首创分子监督的细胞级病理基础模型**：将配对空间转录组学作为 H&E 细胞形态的自动标签源，彻底摆脱对昂贵且不一致的人工核标注的依赖，与依赖人工绘制边界的传统管线本质不同。
2. **构建 1540 万细胞规模的跨器官配对数据集**：整合 81 张 Xenium 切片与 16 器官，通过聚类-标记基因注释-人工审查-置信度过滤四级管线生成 23 类细胞标签，填补了现有数据集规模小、跨器官类别不统一的空白。
3. **共享编码器+多任务器官特异性分类头架构**：设计“一个 ViT 骨干 + 16 个 per-organ 线性头”的多任务结构，使模型能同时学习跨组织的通用细胞形态特征并适配器官特异性分类边界，避免单一全局分类器难以覆盖跨器官形态变异的问题。
4. **全面的细胞级表征验证与主动学习优势**：在空间留出测试集、四个专家标注基准（Linear/Full fine-tuning）及结直肠癌正常上皮识别的主动学习场景中，均显著领先六种主流病理基础模型，证明分子监督预训练能学到泛化的细胞级底层表征。

## 方法详解
- **标签构建管线**：细胞表达谱经 Scanpy 归一化、log(1+x) 变换、PCA 与 Leiden 聚类（分辨率 0.8）后，通过 Wilcoxon 秩和检验计算 Top-30 标记基因进行聚类注释；所有器官的聚类均经人工逐一审视以剔除 artifact/doublet；细胞级置信度由邻居纯度（k=50 PCA 空间中同簇邻居比例）与标记基因边际得分（自身簇标记均值减去最强竞争簇标记均值，归一化至 [0,1]）的平均值计算，仅保留置信度 >0.6 的细胞用于训练。
- **图像块提取**：将 Xenium 细胞坐标通过官方配准矩阵映射至 H&E 像素空间，以细胞核质心为中心裁剪 56×56 μm 窗口，resize 至 224×224 像素；利用组织 mask 剔除出界/撕裂区域，并通过 Laplacian 方差阈值（10）过滤失焦图块。
- **模型架构**：骨干为 ViT-giant（patch size 14，输出 1536 维 embedding），初始化自 UNI2-h 并端到端微调； pooled class token 经 LayerNorm 后接 Dropout 0.25，再输入 16 个器官专属线性分类头（共 103 类输出），前向传播时由器官 ID 路由。
- **训练设置**：AdamW（weight decay 1e-2），骨干 LR 2e-5、头部 LR 1e-3；1 epoch 线性 warmup + cosine decay；梯度裁剪 1.0；bfloat16 混合精度，batch size 256，4× NVIDIA B200 GPU；数据增强含随机翻转、180°旋转及颜色抖动（brightness/contrast/saturation 0.1, hue 0.02）；早停基于验证集 macro-F1（patience 5），最佳 checkpoint 位于第 5  epoch。
- **感受野消融**：固定同一批细胞，分别以 28/56/112/224 μm 裁剪并统一 resize 至 224px，56 μm 在 macro-F1 与准确率上均最优（paired bootstrap p<0.001 vs 28/224 μm），兼顾核级诊断分辨率与邻近组织上下文。

## 实验与结果
- **内部空间留出评估**：测试集 294 万细胞覆盖全部 16 器官，CytoFormer 达到准确率 0.846、macro-F1 0.779。形态特征鲜明类别表现接近完美（肝细胞 98.1、肾小管 97.8、鳞状上皮 95.7、胰岛 94.8、肿瘤 92.8）；最难类别为软骨细胞（37.6）、神经（46.4）、髓系祖细胞（46.7）与巨噬细胞（62.4），误差集中于单核细胞混淆与上皮-肿瘤边界。全切片预测可完整还原组织架构（导管、间质带、免疫聚集区位置高度一致）。
- **线性微调基准对比**：在 PanNuke、CoNSeP、MoNuSAC、PUMA 四个专家标注数据集的 25 个设置中冻结编码器仅训练线性头，CytoFormer 在 24/25 设置取得最佳 macro-F1（平均 79.2 vs 次优 71.4），对未见器官（膀胱、食管、甲状腺等 9 个）与未见细胞类型（如 PUMA 中的黑色素吞噬细胞）同样有效。
- **全参数微调基准对比**：端到端微调后，CytoFormer 在 CoNSeP 内皮细胞（66.0 vs 45.1）、PanNuke 结缔组织细胞（80.6 vs 79.0）等难点类别上仍显著领先，证实预训练提供了强力的初始化起点。
- **主动学习标签效率**：在结直肠癌 VisiumHD
