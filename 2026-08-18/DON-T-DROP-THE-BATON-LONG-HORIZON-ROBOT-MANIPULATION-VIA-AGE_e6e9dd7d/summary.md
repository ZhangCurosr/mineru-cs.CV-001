# 论文速读：DON-T-DROP-THE-BATON-LONG-HORIZON-ROBOT-MANIPULATION-VIA-AGE

## 一句话总结
本文提出 **BATON**，一种面向长程机器人操作的编程智能体框架。通过将子任务作为独立探索单元、将阶段间过渡（transition）显式建模为语言契约，在冻结 VLA 上实现零参数更新的测试时探索，使长程任务成功率显著超越仅依赖阶段级技能的现有方法。

## 研究问题与动机
- **长程组合失效**：VLA/WAM 在单技能上已高度可靠，但将它们串联成千步级任务时，整体成功率远低于各阶段独立成功率（如 $\pi_{0.5}$ 阶段成功率约 50%，全任务仅 ~10%）。
- **误差累积与状态漂移**：端到端 VLA 过拟合演示的初始状态分布，阶段间残留误差导致协变量偏移，策略既无法识别也无法纠正漂移。
- **全任务探索成本爆炸**：既有“智能体+冻结 VLA”方案在长程场景下需联合搜索所有阶段的调度、姿态与调用时机，成本随阶段数 $K$ 呈 $T^K$ 指数增长，且单次失败无法定位具体断裂阶段。
- **过渡缺失**：现有方案仅关注子任务内部，VLA 调用无入口条件，阶段边界无状态复原机制，前一技能的成功实现可能使后一技能起始状态非法。

## 核心贡献（创新点）
- 提出 BATON，**首次**将编程智能体与冻结 VLA 结合实现端到端长程操作，全程零参数更新，仅靠测试时试错与语言记忆进化。
- 设计**分层子任务探索**机制，将探索单元从“全任务”降为“单子任务”，使探索成本从指数级 $T^K$ 降至可加的 $T \cdot K$，并实现失败阶段精准归因。
- 构建**过渡感知记忆**（transition-aware memory），显式建模三种过渡：子任务内调用过渡、跨任务交接过渡、跨任务前瞻过渡，形成可语言书写、运行时校验、失败回写的“交接契约”。
- 在 RoboMemArena 千步级家庭任务上，BATON 较当前 SOTA 提升 **TSR +11.6%**、**CSR +14.9%**，并超越提供完美历史记忆的 Oracle 基线。

## 方法详解
- **任务分解与加法探索**：给定长程指令，智能体将其拆解为有序链 $\mathcal{T} = u_1 \triangleright \sigma_{1,2} \triangleright \dots \triangleright u_K$。对每个无记忆的子任务 $u_k$，在短程 regime 内运行引导探索循环（基于 Harness VLA），遍历调度顺序、预接触姿态与 VLA ACT 调用时机。失败记录写入失败记忆以避开重复试错，首次成功后以符号化感知查询形式存入记忆。验证通过的对子逐级组合，边界契约单独记录，确保搜索始终停留在可管理的子任务尺度。
- **三种过渡的显式建模**：
  1. **调用过渡（Invocation transition, $\sigma_k^{act}$）**：位于子任务内部，控制权从智能体移交至冻结 VLA。引入 **Verifier Agent**，仅当手腕相机图像满足显式就绪条件（如“两侧手指出现在把手两侧”“夹爪完全进入容器四边内”）时才触发 VLA ACT；若条件不满足则用解析原语重新 staging 后再次校验，杜绝越界调用导致的分布外失败。
  2. **交接过渡（Handoff transition, $\sigma_{k,k+1}$）**：解决前驱子任务残差污染后继起始状态的问题。边界处记录入口条件（如“夹爪恢复垂直、张开并悬停于目标上方”），Verifier Agent 在阶段切换前用解析原语复原状态，使后继子任务从合规起点开始。
  3. **前瞻过渡（Lookahead transition）**：解决“局部成功但后继无法继承”的逆向依赖。**Scheduler Agent** 在执行 $u_k$ 前读取剩余计划 $\mathcal{P}_{>k}$，收集后继施加的执行约束，从记忆中检索满足约束的竞争策略（rival）；若无匹配项，则带回新约束重新探索。
- **统一存储结构**：记忆 $\mathcal{M}$ 由节点（子任务轨迹与失败记录）和边（边界契约）构成。同一子任务可并存多种竞争策略，检索时按当前计划剩余部分动态路由；契约违反时将违规原因写回并排除该策略，实现条件泛化且无需梯度更新。

## 实验与结果
- **数据集与协议**：RoboMemArena 基准，含 26 个千步级家庭任务（4 类：transferring、occlusion、counting、sequence），68.9% 子任务依赖历史记忆。探索与评测按场景 seed 严格分离（seed 50 探索，seed 51/52 评测取平均）。
- **基线**：$\pi_{0.5}$、HiF-VLA、MemoryVLA、MemER、PrediMem（含 GT oracle）、FrameSamp+Modul，以及未加过渡记忆的原始 Harness VLA。
- **主要结果**：BATON 取得 **TSR 57.7%**、**CSR 78.8%**，较最强报告方法 FrameSamp+Modul 分别提升 **+11.6%** 与 **+14.9%**；同时超越提供完美历史记忆的 PrediMem Oracle（46.1% TSR / 64.8% CSR）。在 occlusion（50.0 vs 39.1）与 counting（68.8 vs 31.4）类别上优势尤为突出。
- **关键结论**：阶段级技能 competence 不保证长程组合成功；传统回溯记忆仅能缓解计数/序列类问题，无法修复过渡耦合。将 transition 显式化为语言契约可同时压低探索成本与边界失败率。

## 相关工作脉络
- **长程机器人操作**：主流方案通过大规模预训练（$\pi_{0.5}$、OpenVLA）或记忆增强（MemoryVLA、MemER）提升单技能鲁棒性，但 BOSS 基准指出 34–67% 失败源于边界状态偏移。HANDFUL、Foresight Residual RL 等训练型方法虽能修正边界，但需梯度更新且绑定固定后继策略；BATON 以零样本语言契约替代，一次性学习可跨任务复用。
- **技能库与具身记忆**：Voyager、HiMe 等系统通常对单技能仅保留一条 canonical 轨迹，按指令或上下文检索。本文指出这种“去歧义”在边界处是缺陷：后继任务往往依赖当前任务的具体执行策略（如侧向抓取 vs 顶部深握）。BATON 保留竞争策略并按剩余计划动态检索，比任务导向抓取（task-oriented grasping）与 TAMP 更轻量且无需人工谓词。
- **冻结 VLA 的智能体控制**：Harness VLA 首次将冻结 VLA 封装为可重试原语加入编程智能体工具集，但未解决长程探索成本与过渡缺失。ASPIRE、Volo、Hi-Robot 等偏重推理调度或世界模型预测，均未约束单次 VLA 调用后的终端状态对后继的影响；BATON 将 transition 作为探索与学习的核心单元，补全了这一缺口。

## 局限性与未来方向
- **推理与交互延迟**：依赖 LLM 智能体的多次试错与 Verifier/Scheduler 推理，千步级任务的实际完成耗时与 token 消耗较高，文中未报告端到端延迟预算。
- **传感器依赖**：调用与交接过渡高度依赖手腕相机的稳定观测，在严重遮挡、光照剧变或缺失 wrist camera 的平台上的泛化性待验证。
- **分解先验假设**：方法假设长程任务可被合理切分为短程接触丰富的子任务，对于高度连续、语义边界模糊的操作序列（如流体倾倒、软体形变），自动分解的可靠性存疑。
- **未来方向**：可探索轻量级视觉就绪检测器替代纯 LLM Verifier；将过渡契约与在线微调结合以压缩探索轮次；扩展至动态非结构化环境或多机器人协作场景。

## 研究启发与可借鉴点
- **Transition 作为一等公民**：将“阶段间过渡状态”显式建模、校验与存储，而非仅关注节点技能，这一视角可直接迁移至 LLM Agent pipeline、自动驾驶分层规划、多机械臂协同等长程序列决策任务。
- **加法探索范式**：通过子任务隔离与层级组合，将试错成本从 $O(T^K)$ 降至 $O(TK)$，并结合失败归因与记忆复用，为复杂技能组合的测试时优化提供了可扩展的通用框架。
- **语言契约式记忆库**：以自然语言描述 readiness condition 与 execution constraint，支持人类可读、可审计、可编辑，且竞争策略按场景动态检索的存储设计，可作为后续多策略编排系统的标准模块。
- **Verifier/Scheduler 角色解耦**：将“状态就绪判断”与“策略路由决策”分离为独立 Agent 角色，既保留 LLM 的语义推理灵活性，又将控制流交给确定性几何/视觉条件，有效平衡了探索效率与执行可靠性。
