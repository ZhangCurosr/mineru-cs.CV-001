# 论文速读：FUSE: Frame-Unified Stress Estimation from Facial Video

## 一句话总结
论文提出了 **FUSE**（Frame-Unified Stress Estimation）框架，将完整的面部视频录制作为一个统一输入进行压力检测，无需传统的短时时序窗口划分与聚合，并通过轴折叠（axis folding）结合不对称注意力架构实现对长序列的高效处理。

## 研究问题与动机
- 现有视频压力识别方法普遍将连续录制分解为固定长度的短时片段（clips/windows），引入了窗口长度、重叠率、聚合策略等额外设计选择，且会丢弃窗口边界外的时序上下文信息。
- 不同数据集与场景下最优窗口超参存在差异，限制了模型的泛化能力；完整记录的时序信息未被充分利用。
- 长视频处理面临计算复杂度高、显存占用大等挑战，如何在保持全局感知能力的前提下实现高效推理仍是开放问题。
- 缺乏系统性地评估“完整录制端到端处理”可行性的研究，本文旨在验证在不进行外部时序分割的情况下是否仍能实现有效压力识别。

## 核心贡献（创新点）
1. **提出 FUSE 框架，实现完整视频的统一处理**：将时间维度折叠进通道维度，使整个录制序列以单一 2D 表示输入模型，无需外部时序窗口划分。与传统将视频切成短时 clip 再分类的方法本质不同。
2. **设计不对称注意力架构**：采用 segment state（潜状态）与空间 token group 之间的跨注意力，配合全局自注意力，以紧凑表示高效处理高维输入。与标准自注意力相比，计算复杂度显著降低。
3. **系统评估时序步长（stride）配置**：从全帧密集采样（τ=1）到稀疏子采样（τ=30）进行了全面的性能–计算代价权衡分析，揭示了并非采样越密效果越好。
4. **验证全记录推理的可行性**：在 58 人数据集上，全帧输入（τ=1）仍可达到较高测试准确率（69.03%），且最佳配置 τ=15 在较低计算成本下取得最高准确率（69.44%），证明无需窗口化的完整性推断是可行的。

## 方法详解
- **Video Tokenization（视频词元化）**：
  - 输入视频在 T 帧（30 fps）下以时间步长 τ 采样，保留 L = ⌊T/τ⌋ 帧，每帧为 224 × 224 RGB 图像。
  - 执行 **轴折叠（axis folding）**：将时间维度折叠到通道维度，得到张量 **X** ∈ ℝ^(B×H×W×3L)，其中 H = W = 224。
  - 使用 **傅里叶特征（Fourier features）** 对空间位置 p ∈ [-1, 1]^2 进行编码，K=6 个频率带，f_max=10，共增加 26 个位置特征。
  - 将空间轴展平成 N = H×W = 50176 个 token，每个 token 维度 C' = 3L + 26。
  - 将 token 序列划分为 **S = 4** 个连续空间组（segments），每组 n_s = N/S = 12544 个 token。

- **Asymmetric Attention（不对称注意力）**：
  - 网络共 **4 层**，每层包含 **1 个跨注意力块（cross-attention）** 和 **R_ℓ 个自注意力块（self-attention）**，ℓ=0,1,2,3。
  - 每层维护 **S = 4 个 segment states**，初始化为共享向量 **l_init** ∈ ℝ^d₀（由 M₀=32 个可学习参数平均得到，d₀=128）。
  - **跨注意力**：查询为单向量 e_s^(ℓ-1) ∈ ℝ^(B×1×d_ℓ)，键/值为对应空间组的 token 子集 T̃_s ∈ ℝ^(B×n_s×C')，注意力矩阵为 1×n_s（非方阵）。使用单头，头维度逐层为 {64, 48, 32, 16}。
  - **自注意力**：将所有段状态堆叠为 E^(ℓ) ∈ ℝ^(B×S×d_ℓ)，应用多头自注意力，头数与维度逐层递减。重复 R_ℓ ∈ {8,6,4,2} 次。
  - **分层压缩**：段状态维度逐层递减 d_ℓ ∈ {128,112,96,80}，段数固定为 S=4。
  - 最终段状态平均后经线性分类头输出预测。所有注意力使用预层归一化、残差连接，attention/feedforward dropout = 0.10。

## 实验与结果
- **数据集**：58 名成年人（24 男 34 女，年龄 26.9±4.8 岁），包含社交暴露、情绪回忆、心理负荷、压力视频刺激四阶段；60 fps 记录，下采样至 30 fps，分辨率 608×800。
- **协议**：受试者层面分层划分（38 训练 / 8 验证 / 12 测试），避免受试者难度不平衡导致的性能膨胀。二元分类（中性 vs 压力）。
- **主要结果（视频模态）**：
  - **最高测试准确率**：**69.44%**（τ=15），计算代价 24.07 GFLOPs，参数 5.93M。
  - **全帧配置（τ=1）**：测试准确率 **69.03%**，计算代价 348.78 GFLOPs，参数 9.16M，推理延迟 133.02 ms。
  - **验证准确率峰值**：70.42%（τ=20）。
  - 计算代价随 τ 增大急剧下降：τ=30 时仅需 12.48 GFLOPs，参数 5.82M，延迟 14.77 ms，约 28 倍计算节约。
- **结论**：时序密度超过一定阈值后并未带来一致的性能提升；中等稀疏采样（τ=15）可在更低计算成本下取得最佳泛化；完整录制处理在架构上无需修改即可支持不同 τ。

## 相关工作脉络
- **Zhang et al. [14]**：将 2 分钟录制分成 15 秒样本进行深度学习压力识别；本文与之相比，无需固定样本划分，直接处理完整序列。
- **Jeon et al. [15]**：使用 2 秒短时片段建模面部时空动态；本文突破了对短片段的依赖，支持长时上下文建模。
- **Valergaki et al. [16]**：基于 Transformer 的非重叠窗口方法；本文消除外部窗口化，通过内部空间分组实现类似功能。
- **Ding et al. [23]**：帧级特征提取结合时频域聚合；本文统一编码全序列，避免聚合带来的信息损失。
- **Perceiver [28]**：引入的不对称注意力思想的源头；本文将其应用于轴折叠后的视频表示，专注于全记录处理。
- **ViViT [27]**：保留显式时间轴的管状嵌入视频 Transformer；本文彻底折叠时间轴，实现纯 2D 表示处理。

## 局限性与未来方向
- **数据集与任务单一**：仅在单个 58 人数据集上进行二元分类，未扩展到更细粒度的压力等级或更多样化场景。
- **缺少与窗口化基线的直接对比**：未在同一受试者划分下与主流窗口化方法进行公平比较，限制了结论的强弱程度。
- **全帧配置计算成本较高**：τ=1 时需 348.78 GFLOPs，推理延迟 133 ms，在资源受限部署中存在挑战。
- **未来方向**：扩展到多数据集、细粒度回归或多分类任务；与窗口化方法进行系统对比；优化长序列推理效率；探索与生理信号（如 ECG）的多模态融合。

## 研究启发与可借鉴点
- **轴折叠技术可迁移**：将时间维度折叠进通道维度的思路可应用于其他时序信号（如 ECG、EDA、呼吸信号）的统一表示学习。
- **不对称注意力的高效性**：通过 segment state 压缩高维 token 序列，在保证全局感知的同时显著降低计算开销，适合长视频或高分辨率序列建模。
- **步长 sweep 实验设计**：系统评估不同时序采样密度下的性能–效率权衡，为视频分析模型提供了可复用的评估范式。
- **空间分组替代时间分组**：将 token 沿空间轴分组而非时间轴，避免了窗口化带来的边界信息丢失问题，启发其他任务中类似的内部结构划分策略。
- **简化管线设计**：单一架构处理变长输入，消除了窗口切分、聚合等后处理步骤，降低了超参数调优负担，便于工程部署。

## 关键术语表
- **FUSE (Frame-Unified Stress Estimation)**：本文提出的框架，将完整面部视频作为统一输入进行压力估计，无需时序窗口划分。
- **Axis folding（轴折叠）**：将时间维度折叠到通道维度的操作，使视频序列变为高维 2D 空间表示。
- **Asymmetric attention（不对称注意力）**：查询与键/值在维度或数量上不对等的注意力机制，此处指 segment state 对空间 token 组的跨注意力。
- **Temporal stride（时序步长 τ）**：视频采样的间隔参数，控制输入序列的帧数与密度。
- **Segment state（段状态）**：每个空间 token 分组对应的潜向量，通过跨注意力从组内 token 聚合信息。
- **Fourier features（傅里叶特征）**：使用正弦/余弦函数对空间位置进行编码的特征表示，增强模型对位置的敏感性。
