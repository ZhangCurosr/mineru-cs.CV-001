# 论文速读：Unlocking the Power of Medical Tabular Data via Semantic-Aware Multimodal Pre-training

## 一句话总结
本文提出 **AID** 框架，通过语义感知的多模态自监督预训练策略，显式建模医疗表格数据的二维层级结构（跨特征诊断重要性差异与特征内连续-离散对偶性），在皮肤科与眼科大规模数据集上建立新 SOTA，显著提升跨模态表示的泛化能力与线性可分性。

## 研究问题与动机
- **标签稀缺与多模态融合的必要性**：临床决策高度依赖视觉证据（如皮肤病灶图像）与结构化患者数据（如实验室指标、人口统计学特征）的联合分析，但高质量专家标注成本高昂，亟需利用海量无标签图像-表格对进行自监督预训练。
- **现有方法的语义无关设计**：主流多模态预训练方法（如 MMCL、TIP）将表格输入视为扁平向量，采用均匀掩码策略处理所有临床特征，忽视了不同特征在诊断任务中的重要性差异。
- **连续数值回归的优化瓶颈**：现有方法对被掩码特征执行直接的连续值回归（如 MSE），导致严重的病态优化：视觉上难以区分的细粒度数值（如 0.61 vs 0.65）被要求精确回归，不仅易引发过拟合，还阻断了模型捕捉高层跨模态语义关联的能力。
- **缺乏对表格二维结构的建模**：医疗表格数据具有天然的“跨特征重要性层级”与“特征内连续性-离散性对偶”，现有预训练目标均未显式刻画这两类结构，限制了表示学习的上限。

## 核心贡献（创新点）
1. **提出 AID 语义感知预训练框架**：首次将医疗表格的二维层级结构引入多模态自监督学习，打破传统语义无关（semantic-agnostic）的表征范式。
2. **设计 Importance-Aware Adaptive Masking**：利用冻结的 TabPFN v2 结合无标签 PCA 伪标签离线提取特征重要性，构建无需下游目标泄漏的自适应课程掩码，高诊断价值特征被优先掩码以强化跨模态依赖。
3. **提出 Soft-Label Discretized Module**：用基于分位数与三角形核的软标签分布匹配替代不稳定的连续回归，数学上保留临床测量的序数关系，提供更稳定的重建目标。
4. **跨病种 SOTA 与强泛化验证**：在皮肤科（SLICE-3D、HOP）与眼科（EyePACS）基准上全面超越现有 SSL 与监督基线，并证明该设计对地理分布偏移具有显著鲁棒性。

## 方法详解
- **整体架构**：包含 ViT-base 图像编码器、混合 Transformer 表格编码器与 Cross-Attention 多模态编码器。表格输入根据优化目标条件化处理：跨模态对齐直接使用原始连续数值，局部重建则通过离散化模块转换为软概率分布。
- **重要性提取与自适应掩码**：
  - 离线阶段对标准化表格矩阵进行 PCA，取第一主成分中位数生成平衡的二值伪标签。
  - 用冻结的 TabPFN v2（预训练于大规模生成式表格分布）拟合伪标签，通过注册 forward hooks 提取各层 Query、Key 与 Self-Attention 权重矩阵，经 L1 归一化与 Min-Max 缩放得到全局重要性向量 $s$。
  - 每个连续特征 $j$ 的掩码率按 $r_j = \min(r_{\mathrm{base}} + \alpha s_j, r_{\max})$ 动态计算，高重要性特征获得更高掩码率，迫使编码器依赖跨模态视觉线索重建。掩码操作使用可学习特殊 Token 替换，避免随机边缘值替换引入的表征噪声。
- **软标签离散化模块**：
  - 按训练集分位数划定 $B$ 个离散区间，避免等宽分箱导致的语义目标严重偏斜。
  - 对落入区间 $c$ 的值 $v$，计算区间内相对位置 $p = (v - b_{c-1}) / (b_c - b_{c-1})$，利用三角形核将概率质量按比例分配给当前区间 $c$ 与相邻区间，形成软标签分布 $q_b$，满足 $\sum_{b=1}^B q_b = 1$。
- **预训练损失函数**：
  $\mathcal{L}_{\mathrm{AID}} = (\mathcal{L}_{\mathrm{ITC}} + \mathcal{L}_{\mathrm{ITM}} + \mathcal{L}_{\mathrm{DR}}) / 3$
  - **ITC**：图像-表格全局对比对齐损失。
  - **ITM**：细粒度二值匹配损失，采用 batch 内 hard negative mining（基于 ITC 相似度动态采样失配对），且负样本完全来自未被掩码的全局表征，保证语义有效性。
  - **DR**：离散化重建损失。对 $D_{\mathrm{cat}}$ 个分类特征使用 Cross-Entropy，对 $D_{\mathrm{con}}$ 个连续特征使用 KL 散度：
    $$\mathcal{L}_{\mathrm{DR}} = \frac{1}{2} \left( \frac{\sum_{i,j} m_{i,j} \mathrm{CE}(\hat{y}_{i,j}, y_{i,j})}{\sum m_{i,j}} + \frac{\sum_{i,k} m_{i,k} \mathrm{KL}(p_{i,k} \| q_{i,k})}{\sum m_{i,k}} \right)$$

## 实验与结果
- **数据集**：
  - **SLICE-3D**：40万+ 标准化皮肤病灶图块，按患者地理位置严格划分 In-Domain (ID) 与 Out-of-Domain (OOD) 测试集，正负样本比 1‰。
  - **HOP**：私有皮肤科数据集，208,540 图像，284 名患者。
  - **EyePACS**：开源眼科视网膜 fundus 图像，88,702 张，经 AutoMorph 管线处理。
- **评估基线**：监督方法（ViT-B, CatBoost, FT-Trans, DAFT, TabPFN v2, Dino v3）与 SSL 预训练方法（SimCLR, SCARF, SAINT, MMCL, TIP, CITab）。
- **主要结果**：AID 在所有基准上取得 SOTA。SLICE-3D OOD 集全微调 AUC 达 **0.944**（对比最强语义无关基线 TIP 的 0.911，提升 **+0.033**），pAUC **0.162**；SLICE-3D ID 集线性探针 AUC **0.984**，已超越 TIP 全微调的 0.971，表明特征空间具备极强线性可分性。HOP 集微调 AUC **0.926**；EyePACS 集准确率 **0.740**，QWK **0.758**。
- **消融结论**：移除自适应掩码使 OOD AUC 从 0.944 降至 0.930；移除 DR 损失或改用等宽分箱/硬标签/高斯核均导致性能下滑，验证三角形核软标签在保留序数关系方面的最优性。

## 相关工作脉络
- **MMCL / TIP**：图像-表格多模态 SSL 的代表性工作，采用对比学习+掩码重建，但将表格视为扁平向量且采用统一掩码与连续回归，未建模特征语义层级，本文在此基础之上引入诊断重要性感知。
- **SAINT / SCARF**：表格单模态 SSL 基线，侧重于行注意力与随机特征增强，未涉及跨模态视觉对齐，本文将其思想扩展至视觉-表格联合预训练。
- **TabPFN v2**：新型表格基础模型，本文借用其冻结权重作为特征依赖性的元学习先验（而非直接用于下游预测），为无标签重要性提取提供可靠归纳偏置。
- **DAFT / FT-Trans**：监督式多模态融合架构，依赖大量标注数据且泛化受限，本文证明在标签稀缺场景下语义感知 SSL 可超越此类强监督方法。
- **Dino v3**：纯视觉强自监督基线，本文工作填补了视觉与结构化表格联合预训练中语义结构建模的空白，实现 1+1>2 的跨模态增益。
- **CITab**：较新图像-表格 SSL 方法，突破跨表格特征屏障，但仍沿用语义无关掩码与重建策略，本文进一步细化至特征重要性课程与软标签分布匹配。

## 局限性与未来方向
- **TabPFN 先验的分布敏感性**：特征重要性依赖离线预训练的 TabPFN v2，若下游表格分布与预训练生成分布偏差较大，重要性评分可能失准。
- **分箱数 B=50 为经验设定**
