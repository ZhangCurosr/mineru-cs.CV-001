# 论文速读：InSight-doc: Agentic Visual Perception for Long-Document Understanding

## 一句话总结
InSight-doc 提出了一种智能体视觉感知框架，将视觉分辨率作为自适应推理资源，通过从低分辨率概览开始、选择性放大高分辨率区域来主动获取证据，从而在长文档理解中显著提升了准确率并降低了推理延迟与幻觉。

## 研究问题与动机
1. 长文档理解需要处理大量视觉上丰富的页面，端到端处理高分辨率图像会导致计算开销巨大（O(N²) 注意力成本），且易引发上下文腐烂（context rot），即模型性能随上下文长度增加而显著下降。
2. 现有方法主要分为三类：端到端高分辨率处理（计算成本高、可扩展性差）、基于外部检索器的视觉 RAG（检索与推理解耦、依赖 k 值选择、可能遗漏关键证据）、粗到精方法（仅进行页面级检索，未实现子页面级定位）。
3. 多跳查询和多轮自我修正需要在统一的多模态推理链中支持区域级证据获取，而现有视觉搜索方法主要评估于自然图像或单页文档，缺乏对多页面长文档的理解能力。
4. 如何在不依赖外部检索器的情况下，让模型自适应地决定何时、何地以及如何放大视觉证据，以实现精度与效率的平衡，是本研究的核心动机。

## 核心贡献（创新点）
1. **提出 InSight-doc 智能体框架**：首次将视觉分辨率作为推理时自适应资源，通过端到端、无需检索器的多轮放大交互实现主动视觉感知，区别于静态高分辨率处理或外部检索方法。
2. **构建大规模主动感知训练语料库**：制作了包含 17.9K 高质量 SFT 示例（带区域级放大轨迹）和 19.2K 硬 RL 示例的数据集，专门针对多跳、多页面文档 QA 进行训练。
3. **实现精度与效率的双重提升**：InSight-doc-8B 在多个文档 VQA 基准上相比基线提升 4.3–16.4 个准确率点，同时在长文档上减少超过 40% 的幻觉率和 41%–68% 的推理延迟。
4. **揭示工具使用需配合策略训练**：证明仅提供放大工具不足以提升性能，必须通过 SFT+RL 训练使模型学会何时放大、如何整合多尺度证据，否则可能导致冗余或停滞轨迹。
5. **提供理论化的延迟与序列长度分析**：给出相对序列长度和推理延迟的上界公式，并与实验结果一致，为方法设计提供理论支撑。

## 方法详解
1. **初始化视觉上下文**：将原始高分辨率文档页面图像按缩放因子 \( r \leq 1 \) 下采样，形成初始视觉上下文 \( \mathcal{I}_{\text{ctx}}^{(0)} \)，以减少初始 token 消耗。
2. **推理‑动作循环**：模型在每轮基于当前上下文生成思维链（CoT），并决定是否需要放大；若需放大，则发出工具调用 \( \text{zoom\_in}(k, d, b) \)，其中 \( k \) 为目标图像索引，\( d \) 为自然语言描述的区域，\( b \) 为边界框。
3. **区域裁剪与放大**：从对应高分辨率源图像中按边界框裁剪出区域，并按缩放因子 \( c > 1 \) 放大（公式 (1)），得到高分辨率证据图像，追加到视觉上下文中。
4. **递归放大与上下文更新**：对于递归放大，更新缩放因子 \( r \leftarrow c \cdot r \)，并不断将新裁剪图像加入上下文，直到模型决定回答或达到工具调用次数上限。
5. **数据构建流程**：使用 InSight‑o3 两代理轨迹生成器（vReasoner 负责推理与区域请求，vSearcher 负责定位边界框）合成放大轨迹，经三阶段过滤（prior‑only filtering、zoom‑free filtering、CoT 构造）后分为 SFT 和 RL 数据；成功轨迹进入 SFT，失败轨迹进入 RL。
6. **训练策略**：SFT 阶段使用标准语言模型损失在全参数上微调；RL 阶段采用 GRPO 算法，仅以二元准确性作为奖励，通过加权采样平衡可回答与不可回答样本。
7. **成本分析**：推导了相对序列长度（Proposition 1）和推理延迟（Proposition 2）的上界公式，表明在典型参数范围内，方法可将序列长度降至基线的 7.8%–45.0%，延迟降至 41%–68%。

## 实验与结果
- **数据集**：DUDE、MP‑DocVQA（中等长度文档）；MMLongBench‑Doc、LongDocURL（长文档）；MME‑RealWorld‑Lite、O3‑Bench（通用高分辨率图像）。
- **评估基线**：GPT‑5.4‑nano/mini、Gemini‑3.1‑Flash‑lite 等专有模型，以及 InternVL3‑8B、GLM‑4.6V‑Flash、Qwen3‑VL‑8B 等开源模型。
- **主要结果**：
  - 在低初始分辨率（r=0.25）下，InSight‑doc‑8B (SFT+RL) 平均准确率达 66.9%，比 Qwen3‑VL‑8B 基线提升 16.4 个点；在中等分辨率（r=0.5）下平均准确率 72.6%，提升 4.3 个点。
  - 在各基准上均保持稳定增益：DUDE +17.2 点、MP‑DocVQA +18.3 点、MMLongBench‑Doc +17.1 点、LongDocURL +12.8 点（r=0.25）。
  - 在长文档上，幻觉率降低超过 40%，推理延迟降低 41%–68%（例如在 70 DPI 下比 140 DPI 基线延迟降低 54%，同时准确率提升 1.2 点）。
  - 在通用高分辨率 VQA 上，InSight‑doc 同样优于基线，证明其泛化能力（如 MME‑RealWorld‑Lite 在 r=0.25 达 48.2%，超越 GPT‑5.4‑nano 的 47.8%）。
- **轨迹质量分析**：RL 训练后证据框覆盖率提升至 82.3%（r=0.25），冗余轨迹从 14.1% 降至 5.8%，停滞轨迹几乎消除（0.1%）。

## 相关工作脉络
1. **端到端文档理解方法**（如 Qwen‑VL、InternVL 系列）：直接将所有高分辨率页面输入模型，保留细粒度信息但计算开销大，缺乏主动证据获取能力。
2. **视觉检索增强生成（V‑RAG）**（如 VDocRAG、VRAG‑RL）：依赖外部检索器选择相关页面，检索与推理解耦，性能敏感于 k 值，且可能遗漏关键证据。
3. **粗到精方法**（如 CogDoc、Doc‑V⋆）：先从低分辨率扫描识别相关页面，再以高分辨率检查，但仍限于页面级定位；Doc‑V⋆ 主要依赖外部检索器（ColQwen2.5），而 InSight‑doc 完全端到端。
4. **视觉搜索与“用图像思考”**（如 DeepEyes、Pixel‑Reasoner、Mini‑o3）：将放大/裁剪内化为模型操作，但主要在自然图像或单页文档上评估，未针对多页面长文档进行系统训练与验证。
5. **本文定位**：InSight‑doc 是首个完全端到端、无需检索器、支持多跳查询和子页面级区域定位的智能体框架，在精度、效率和泛化性上均超越现有方法。

## 局限性与未来方向
- **局限性**：
  1. 仅在 Qwen3‑VL‑8B‑Instruct 基线上实验，未验证其他模型架构或提供商，通用性有待检验。
  2. 未尝试先进的 RL 算法（如 PPO 变体）或更丰富的奖励设计（如效率奖励），存在优化空间。
  3. 训练数据规模相对有限（37K 示例），可能影响模型对更广泛文档类型和问答场景的泛化。
  4. 未评估在不同硬件配置下的实际部署成本与延迟表现。
- **未来方向**：
  1. 扩展至更大参数模型或不同架构（如混合 MoE），验证框架的通用性。
  2. 探索更复杂的 RL 训练策略与多目标奖励（结合准确性、效率、幻觉抑制）。
  3. 扩大训练数据规模并增加多样性（如不同语言、专业领域文档）。
  4. 结合视觉压缩技术（如 DeepSeek‑OCR）进一步降低视觉 token 开销。
  5. 研究在线自适应机制，使模型能根据新文档动态调整放大策略。

## 研究启发与可借鉴点
1. **方法论迁移**：主动感知框架可推广至视频理解（逐帧聚焦关键片段）、遥感图像分析（多尺度区域探索）等需要逐步获取证据的领域。
2. **实验设计借鉴**：引入分辨率缩放因子 \( r \) 和工具调用次数 \( n \) 进行系统分析，为智能体推理的效率‑精度权衡提供量化评估维度。
3. **训练策略参考**：SFT+RL 两阶段训练有效结合模仿学习与策略优化，尤其适用于需要工具使用与多步推理的智能体系统。
4. **数据合成技巧**：使用两代理轨迹生成器（分离推理与定位）然后合并为单代理轨迹，是一种高效、高质量的数据构建范式。
5. **创新机会**：可将放大机制与本团队的多模态检索增强生成（RAG）方向结合，实现更灵活的跨模态证据定位与动态上下文管理。

## 关键术语表
1. **Active Perception（主动感知）**：模型通过工具调用（如放大、裁剪）动态获取视觉证据，而非被动处理固定分辨率输入。
2. **Context Rot（上下文腐烂）**：随着输入上下文长度增加，模型性能显著下降的现象，归因于注意力稀释和长上下文训练数据稀缺。
3. **Coarse‑to‑fine（粗到精）**：先以低分辨率概览整体文档，再选择性放大高分辨率区域的推理策略，平衡信息完整性与计算效率。
4. **Retriever‑free（无需检索器）**：不依赖外部检索模型，模型直接在视觉上下文中自主定位和放大所需区域。
5. **Zoom‑in Tool Call（放大工具调用）**：模型发出的结构化指令，包含目标图像索引、区域描述和边界框，用于裁剪并放大特定区域。
6. **SFT+RL（监督微调+强化学习）**：先通过模仿学习让模型掌握基本工具使用模式，再通过强化学习优化推理策略与轨迹质量。
7. **Evidence‑box Coverage（证据框覆盖率）**：裁剪区域与标注证据框的重叠比例，用于定量评估模型定位精度。
8. **Hallucination Rate（幻觉率）**：在不可回答问题上，模型提供实质答案而非拒答的比例，衡量模型产生无依据输出的倾向。

## 可复现要素
- **数据集**：主动感知语料库（17.9K SFT 示例 + 19.2K RL 示例）已公开，代码和数据集均在 GitHub 发布。
- **代码/权重**：开源地址为 https://github.com/m‑Just/InSight‑doc，包含训练、评估脚本及预训练模型。
- **关键超参**：
  - **SFT**：全局批量大小 32，最大序列长度 65,536 tokens，学习率 5×10⁻⁶，2 个 epoch，余弦学习率调度。
  - **RL**：GRPO 算法，训练步骤 800，全局批量大小 24 prompts，每次 rollout 8 次，学习率 1×10⁻⁶，KL 正则化系数 0.01。
  - **推理**：工具调用上限 10 次，全页图像最大面积 35,002 像素，裁剪图像最大面积 1280² 像素，区域放大因子 2.0。
