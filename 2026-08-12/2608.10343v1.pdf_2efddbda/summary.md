# 论文速读：ENCORE: Efficient Noise Context-Aware Representation for Low-Dose CT Denoising

## 一句话总结
提出 ENCORE 框架，将 CT 噪声上下文（噪声功率与空间相关性）显式建模并融入去噪网络（FlyingConv），在零样本自监督训练设置下实现更优的低剂量 CT 去噪质量与更低的推理延迟。

## 研究问题与动机
- CT 原始投影含泊松量子噪声与高斯电子噪声，重建后回投影还会引入复杂的**空间相关性与非平稳噪声分布**，而大多数现有 DL 去噪模型仍基于 i.i.d. 噪声假设。
- 以 NADD 为代表的“直接拼接随机噪声图”方式波动较大，容易为网络带来不稳定信号，难以稳定利用 CT 噪声统计。
- 传统监督训练依赖高剂量/无噪参考图，容易继承残留噪声；而纯自监督（N2N）缺乏对噪声物理分布的精细约束，在高衰减与极低剂量场景下近似误差显著。
- 现有框架多关注模型理论复杂度（如 MACs），却未对**端到端推理延迟**与硬件加速进行系统化优化。

## 核心贡献（创新点）
1. **基于 Cornish-Fisher 展开的非高斯噪声合成**：在高剂量假设失效的低光子/高衰减区域显式注入泊松偏斜，替代传统 Gaussian 近似，使 N2N 训练分布更接近真实 CT 噪声。
2. **噪声自协方差预处理的“模型友好型”上下文提取**：用局部自协方差图（噪声功率与相关结构）替代原始随机噪声图作为输入先验，显著降低输入波动并提升网络稳定性。
3. **FlyingConv 动态权重卷积模块**：把解剖特征与噪声上下文融合后动态生成卷积核，并采用分组深度可分离策略与 GPU 友好的插值-卷积融合实现，避免静态权重的空间适应不足。
4. **零样本条件去噪（zero-shot conditional denoising）**：通过推理时缩放上下文强度，可在不重新训练的情况下灵活控制“去噪强度—纹理保留”的平衡。
5. **全链路定制 CUDA 加速**：针对 FBP 重建、自协方差估计、FlyingConv 三个关键阶段做缓存/纹理内存优化，整体延迟接近甚至优于部分基线。

## 方法详解
- **噪声合成与 N2N 对生成**：从单张正常剂量投影 $P_{ND}$ 出发，以剂量比例 $d$ 模拟低剂量投影 $P_{LD}$。为避免高斯近似的低光子失效，将 Poisson 项 $\mathcal{N}(0,P_{ND})$ 替换为基于 Cornish-Fisher 展开构造的偏斜噪声 $\mathcal{W}(0,P_{target})$，保留目标方差与泊松偏斜。训练时对同一 Scan 生成统计独立的 $P_{sLD}$ 与 $P_{ID}$ 作 N2N 对。
- **噪声图生成与零样本控制**：在推理阶段生成噪声增强图以估计本地噪声分布。通过设定 $d_{target}$ 引入缩放比 $r=d/d_{target}$，等价于模拟更高剂量场景；$d_{target}=\infty$ 对应最强去噪，$d_{target}=1$ 使残噪接近正常剂量。
- **自协方差估计**：在零均值噪声图 $\mathbf{X}_n$ 上计算局部空间自协方差 $\mathbf{V}(i,j,x,y)$，采用小窗 $w=5$、小滞后块 $p=5$ 并在单样本 $N=1$ 下依靠空间邻域聚合；随后做符号-对数归一化 $\mathrm{sign}(\mathbf{V})\cdot \log(1+|\mathbf{V}|)$ 压缩动态范围。
- **FlyingConv 模块**：先将特征图与协方差图做 $4\times4$ 平均池化后融合，经轻量 Predictor（FasterNet 块+1x1卷积）生成自适应核张量。为避免 per-channel 权重带来的访存开销，采用分组策略（默认 $g=2$）共享相邻通道权重；并通过融合“插值+卷积”的计算路径减少中间显存，末尾接 1x1 卷积补偿通道交互，奇数层替换为 FlyingConv。
- **训练与评估细节**：N2N 训练仅使用 MSE 损失；模型以 DnCNN/UNet/NAFNet/Uformer 为骨干，分 Lite/Base 两档，分别在 10% 与 25% 低剂量下评测 PSNR、SSIM 与 AUHOC，并在相同数据集上做配对 Wilcoxon 检验。

## 实验与结果
- **数据集**：训练/验证 Mayo2016（Siemens）8 例 4,773 切片；测试 Mayo2016 2 例 1,093 切片、Mayo2020（GE，跨厂商）5 例 663 切片，以及家用台架锥束 CT 体模数据。
- **主要定量结果（Base UNet 为例）**：在 Mayo2016 25% 剂量上 +ENCORE 达到 **25.62 dB / 0.8471 / 0.3334**，优于 Vanilla、+NADD、+COV；10% 极低剂量上同样领先（UNet Base +ENCORE 24.07 / 0.8119 / 0.3985）。UNet 整体优于 DnCNN；注意力类（NAFNet/Uformer）延迟更高且收益有限。
- **效率结果**：UNet Base +ENCORE 的 MACs 显著下降（如 DnCNN Base 序列由 70.21G 降至 43.17G），实际推理延迟与 +COV 接近；自定义 CUDA 内核将 FBP、协方差、FlyingConv 分别提速约 4.8×、2.9×、3.2×。
- **消融**：偏斜校正对高衰减切片 SSIM 提升明显；上下文窗口/滞后/样本数 $w=5,p=5,N=1$ 取得最佳效率—质量权衡；分组大小 $g=2$ 最优；改变 $d_{target}$ 可在 PSNR/AUHOC 与 SSIM 间切换以缓解过平滑。

## 相关工作脉络
- **NADD**：以随机噪声图直接增广输入；本文用自协方差作为更稳定的统计先验，并通过 FlyingConv 将上下文嵌入权重而非仅作为拼接通道。
- **Half2Half / N2N 系列**：提供无配对训练范式；本文在相同自监督框架内，强化物理噪声分布建模与空间相关建模，提升分布一致性与鲁棒性。
- **MalleConv / 自适应滤波**：依赖局部图像上下文生成动态核；本文在此基础上引入噪声功率与相关结构，专门适配 CT 特有的解剖—噪声耦合。
- **专用感知损失/GAN 类 CT 去噪**：通过视觉失真函数改善质感但易引发幻觉；本文避免强依赖此类损失，改用物理上下文+零样本控制达成质感调节。
- **LEAP/TIGRE 等开源重建**：本文在其基础上重构为面向 GPU 缓存友好的自定义 FBP，使端到端延迟显著下降。
- **噪声功率谱与像素级噪声估计**：为本文的局部自协方差建模提供理论基础，但本文将该类统计直接工程化到模型输入与权重调制中。

## 局限性与未来方向
- 训练仅依赖仿真数据，未显式建模散射、束硬化的物理效应，真实临床差异仍可能存在。
- MACs 的降低并未完全转化为同等延迟优势，FlyingConv 的动态权重生成仍受显存带宽瓶颈限制。
- 默认 $d_{target}=\infty$ 在均匀解剖区域存在过平滑风险，需依赖零样本调参来平衡 SSIM 与纹理。
- 当前自协方差估计基于局部平稳近似，较大尺度结构依赖仍需进一步验证。
- 未来方向包括：纳入散射/束硬化等物理建模、对自适应核的访存模式做后端重构、探索跨厂商与真实投影数据的迁移。

## 研究启发与可借鉴点
- **“统计先验入网”范式**：将噪声功率/相关结构做成模型友好的特征图并参与权重调制，可作为其他模态（如 MRI、超声）去噪的可复用思路。
- **偏斜/高阶矩校正的低资源落地**：在低计数场景用 Cornish-Fisher 等解析修正替代更复杂采样方案，兼顾物理一致性与训练稳定性。
- **端到端延迟优先的评测方式**：不仅比较 MACs/FLOPs，还把重建—预处理—推理全流程纳入实测延迟，有助于指导工程部署选择。
- **零样本推理条件化机制**：通过单一标量 $d_{target}$ 控制输出纹理/去噪强度，为临床工作流提供无需重训的交互接口。
- **GPU 侧定制化加速**：利用 TMU 插值、缓存友好重排、算子融合等手段，能在中等复杂度模块上取得 2–5× 的吞吐提升。

## 关键术语表
- **Noise2Noise (N2N)**：利用一对无配对的同分布含噪图像进行自监督训练的去噪范式。
- **Noise autocovariance map**：描述噪声在空间局部区域内不同位移下的二阶统计相关结构。
- **FlyingConv**：依据局部解剖与噪声上下文动态生成卷积权重并以高效融合方式执行的卷积算子。
- **Cornish–Fisher expansion**：通过偏斜/峰度等累积量将正态变量映射为目标非对称分布的数学方法。
- **AUHOC**：基于频域块相似度的幻觉度量，值越低表示结构化虚假细节越少。
- **Zero-shot conditional denoising**：在不重新训练模型的前提下，通过推理时调节输入上下文强度实现去噪强度的动态控制。
- **MACs**：Multiply-Accumulate Operations，衡量神经网路算术复杂度的常用单位。
- **NPS (Noise Power Spectrum)**：描述 CT 重建图像噪声随空间频率分布的统计量。
