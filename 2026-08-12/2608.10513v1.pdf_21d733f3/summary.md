# 论文速读：SafeCap: Improving LVLM Safety with Image Captioning Reinforcement Learning

## 一句话总结
提出 SafeCap，一种基于强化学习的自描述对齐框架，通过让 LVLM 先生成安全相关的图像描述再输出答案，并利用冻结文本 LLM 的交叉验证结果塑造奖励，在保持视觉任务性能的同时显著提升多模态安全对齐能力。

## 研究问题与动机
- **视觉通道削弱文本安全对齐**：图像是连续高维信号，越狱攻击可将有害指令嵌入排版图像、对象隐含危险意图或利用 benign 文本配合不安全图像绕过仅基于文本学习到的拒绝策略，造成感知-对齐断层。
- **现有推理时包装器存在信息丢失与脆弱性**：如 ECSO 等 caption-mediated 方法在推理阶段将图像转为文本再依赖下游 LLM 恢复安全机制，但细粒度视觉线索（可见文字、布局、对象属性）易丢失，且防护上限完全绑定下游语言模型的安全推理能力。
- **训练时直接偏好优化难以兼顾安全与效用**：传统 SFT/DPO 直接优化拒绝行为容易导致过度拒绝或损害视觉感知/指令遵循能力，缺乏在“安全识别”与“有用回答”之间的动态平衡机制。

## 核心贡献（创新点）
- **安全感知自描述形式化**：将 LVLM 安全对齐重构为“先生成带标签的图像描述、再基于描述生成最终答案”的结构化推理问题。与现有方法的本质区别在于：不是事后解释或推理时外挂包装，而是将描述作为端到端可训练的安全证据通道。
- **描述中介的双信号强化奖励**：设计结合直接答案奖励与冻结 LLM 交叉验证奖励的复合目标，并引入组件级组归一化与指数风险折扣。与已有 SFT/DPO/RLHF 方法的本质区别在于：利用独立文本-only LLM 验证描述是否真正支撑了安全决策，使中间表征质量直接转化为信用分配信号，而非仅依赖模型自评估或静态偏好对。
- **多协议诊断体系与实证验证**：提出 Direct/DirectCap/Prism 三协议评估框架并给出系统性消融。与以往单一协议报告的本质区别在于：明确分离原生推理、学得的自我描述路径与纯文本迁移路径，证明方法的核心收益集中在训练的自描述路径上，同时揭示不同协议下的风险-效用边界。

## 方法详解
- **响应结构与问题设定**：策略模型 $\pi_\theta$ 对图像-问题对 $(x, q)$ 生成结构化响应 $y = <\mathtt{Caption}>c</\mathtt{caption}>a$，其中 $c$ 为图像描述，$a$ 为最终答案。训练目标并非增加冗余文本，而是让 $c$ 暴露决定安全/不安全的关键视觉证据。
- **GRPO 训练目标**：基于公开 SPA-VL 数据集，每组采样 $K=8$ 个 rollout，优势函数为 $A_i = w_{tmp}\tilde{r}_{i,tmp} + w_{cap}\tilde{r}_{i,cap} + w_{ans}\tilde{r}_{i,ans}$，代入 PPO-clipped GRPO 损失优化。主实验不启用显式 KL loss 与 KL 奖励惩罚。
- **模板奖励 $R_{tmp}$**：规则解析器检查响应是否包含唯一完整且非空的 `<caption>` 块与非空答案，且生成在长度限制内结束；格式失败则跳过下游奖励，仅保留结构信号，防止 rollout 退化到 malformed 或循环。
