# 论文速读：Share First, Route What Remains:

## 一句话总结
本文提出 UniF-MoE，将 MoE 的 FFN 专家解耦为共享块与残差块，首创“先共享、后路由”的 token 自适应分配原则：先由共享专家处理可复用的计算内容，再根据剩余需求动态决定激活多少残差专家，在视觉与语言任务上均取得更优的精度-效率权衡，并显著降低推理延迟与显存占用。

## 研究问题与动机
- 传统 top-k MoE 以完整专家为计算单元且对所有 token 分配相同专家数，导致简单 token 产生冗余计算、困难 token 容量不足。
- 共享专家、细粒度计算与动态路由三者通常被独立设计，但实际决策存在强依赖：提取可复用计算后，剩余内容、最优专家选择及所需容量均会改变，独立路由易造成重复计算或容量错配。
- 现有方法缺乏统一的有序决策机制，无法协调“共享多少、共享什么、残差需几个专家”三个相互耦合的分配问题。
- 通过对层 10 MoE 的诊断发现：共激活专家在部分 value 位置高度对齐；移除对齐位置后路由偏好显著改变；且共享覆盖越高，恢复原始输出所需的残差专家数越少。

## 核心贡献（创新点）
- **揭示共享与残差计算的依赖关系并提出“先共享、后路由”原则。** 与现有工作将共享建模与动态路由并行设计不同，本文证明二者是单向有序依赖，必须先确定可复用部分再决策剩余路由。
- **提出 UniF-MoE 统一框架，通过单一 token 预算联合控制共享宽度、内容与残差专家数。** 与多控制器独立调参架构不同，本框架在同一个 token 依赖预算下按功能顺序协同决策，实现专家内与专家间稀疏性的统一调度。
- **设计累积路由质量与 Gram 正交正则化机制。** 与固定 top-k 或独立阈值路由不同，本方法使激活专家数随共享覆盖动态伸缩，并以正交几何强制路由方向多样化、降低专家重叠。
- **在视觉与语言基准上验证更高的精度-效率权衡。** 与单一追求稀疏或加速的工作不同，本文在降低 FLOPs/显存的同时取得 SOTA 精度，证明有序分解在跨模态任务中的通用有效性。

## 方法详解
- **块级共享-残差划分**：每个专家 FFN 的中间宽度 $H$ 被均匀划分为 $B$ 个对齐块，块 $b$ 的输出为 $E_j^{(b)}(\mathbf{x}) = \sum_{h \in \mathcal{H}_b} \mathrm{GELU}(\mathbf{x}\mathbf{K}_j[:,h])\mathbf{V}_j[h,:]$。所有专家从同一稠密 FFN 初始化，确保块边界对齐。每个 token 的共享专家执行选定块，残差专家执行互补块，无重叠。
- **Token 自适应共享建模**：引入可学习共享嵌入 $\mathbf{W}_{\mathrm{shr}}$，计算共享需求分数 $\alpha(\mathbf{x}) = \tau + (1-2\tau)\sigma(\mathbf{x}\mathbf{W}_{\mathrm{shr}})$，其中 $\tau=(B-1)/B^2$。共享块数 $b(\mathbf{x}) = \mathrm{round}(B\alpha(\mathbf{x}))$，约束保证 $b(\mathbf{x}) \in \{1,\dots,B-1\}$，每 token 至少保留 1 个残差块。
