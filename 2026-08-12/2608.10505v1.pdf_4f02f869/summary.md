# 论文速读：RadFusion: Towards Threshold-Controllable Radiology Report Generation

## 一句话总结
本文提出 RadFusion，首个面向放射学报告生成的阈值可控框架，通过融合校准分类器的类别置信度、VQA 报告生成器与 LLM 重写器，使生成文本的诊断内容可随阈值调节灵活权衡灵敏度与特异性，且其 ROC 性能紧密跟踪底层分类器。

## 研究问题与动机
1. 现有报告生成模型仅输出单一固定文本，缺乏对诊断操作点（operating point）的调节机制，无法适配急诊分诊（重灵敏度）或确认性评估（重特异性）等不同临床场景。
2. 传统感知模型（如图像分类器）虽可通过阈值调控实现 ROC 分析以支持监管审批，但只能输出预定义类别概率，无法描述病灶位置、严重程度、进展等丰富临床细节。
3. 通用领域的可控文本生成方法多聚焦于词元级别属性引导或自置信度估计，未涉及基于疾病类别阈值的诊断行为控制，难以直接迁移至医疗决策场景。
4. 报告生成缺乏与数值置信度对齐的验证路径，无法满足医疗器械监管（如 FDA）对量化 ROC 性能评估与可解释决策边界的预期。

## 核心贡献（创新点）
1. 提出 RadFusion 框架，首次实现报告生成模型的阈值可控性，使生成文本的诊断内容与分类器的 ROC 曲线特征对齐。与已有工作本质区别：不同于仅依赖 token 级属性引导或无置信度输出的生成模型，本文通过感知-生成双轨融合实现临床操作点的显式调控。
2. 设计基于 LLM 的报告重写机制，将分类器的二值化决策与原始报告的临床细节证据池结合，在保持医学事实一致性的前提下强制对齐选定阈值下的阳性/阴性类别。与已有工作本质区别：不依赖模型微调，而是通过结构化指令模板与类别例句字典让现有 LLM 直接执行跨模态诊断对齐。
3. 构建闭环 ROC 评估协议，将阈值扫描、报告重写与标签提取串联，证明生成报告的 AUC-ROC 紧密跟踪底层分类器性能，且灵敏度/特异性较无控制生成显著提升。与已有工作本质区别：首次为报告生成引入监管级 ROC 量化验证路径，使生成文本具备可与分类器比对的数值可验证性。
4. 系统消融三类分类器实现与四种 LLM 重写器配置，验证“独立分类器+支持追问的生成器+LLM 重写”组合的最优性能。与已有工作本质区别：通过可控对比剥离各组件贡献，为多模态医疗生成系统的模块化组装提供实证依据。

## 方法详解
1. **感知模型（分类器）**：以 MedImageInsight (MI2) 为基础，采用 Image-Text-Class Hybrid Contrastive Loss 联合学习图像与类别嵌入，损失函数为 $\mathcal{L} = \mathcal{L}_{\text{image-text}} + \lambda \mathcal{L}_{\text{image-class}}$（前者为 softmax 对比损失，后者为 sigmoid 多标签对比损失）。推理时计算图像特征与类别提示（如 "a chest X-ray showing [CLASS NAME]"）的余弦相似度并除以可学习温度，经 sigmoid 得到类别置信度 $P(C_i=1|I)$，最后通过 Temperature Scaling 在验证集上校准概率校准度。
2. **报告生成模型（QRad Auto-VQA）**：将报告生成重构为自主视觉问答过程 $Q = f_Q(I),\ Y = f_A(I, Q)$，Question Generator 预测临床相关提问序列，Answer Generator 逐题回答并拼接成初始报告。该架构支持追加查询：当低阈值将某类别翻转为阳性时，系统可针对该类别发起 follow-up 问答，获取病灶位置、严重程度等 grounding 细节，避免 LLM 幻觉。
3. **LLM 重写器**：采用 GPT-5 等商用 LLM，输入包括阈值化二值决策 $\{\hat{y}_i\}$、初始报告 $r$ 与证据池 $\mathcal{E}$（初始报告+追加问答答案）。重写指令明确规定：阳性类别缺失则补充、矛盾则修正；阴性类别已提及则删除或否定；非类别内容（影像质量、支持设备等）原样保留。指令中内置每类别的阳性/阴性例句模板字典，建立类别名与自然语言变体的显式映射。
4. **三维阈值扩展**：临床部署可扩展为 $(T_a, T_b, T_c)$ 控制，其中 $T_a \leq T_b$ 划分负/半阳/正三区以支持“疑似并建议复查”的模糊表述，$T_c$ 阈值化紧急度评分以独立标识时间敏感病灶；主实验采用 $T_a = T_b$ 的单阈值情形以保持与分类器 ROC 的直接可比性。

## 实验与结果
1. **数据集与设置**：实验基于公开数据集 MIMIC-CXR（227,835 研究，377,110 张胸片），测试集 2,347 份；评估目标为 Findings 部分，疾病标签体系采用 CheXpert 14 类（排除 No Finding）。
2. **分类器实现对比**：MI2 微调（AVG AUC-ROC 0.90）与 QRad 线性探针（0.91）整体相当，后者在难例（如 Pneumothorax 0.88→0.89）有优势，前者在视觉明显类别（如 Support Devices 0.95）更强；QRad 单 token 概率变体明显落后（AVG 0.73）。
3. **LLM 重写器对比**：GPT-5 default 取得最佳宏平均 AUC-ROC 0.90；移除类别例句模板导致 Fracture AUC 从 0.89 骤降至 0.73、宏平均降至 0.88；更小模型（GPT-5.4-mini）需将推理强度从 default 调至 medium，AUC 才能从 0.76 恢复至 0.89。
