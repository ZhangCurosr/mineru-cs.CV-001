# 论文速读：Bridging Event Streams and DiT: Event-Guided Video Frame Interpolation

## 一句话总结
本文提出了一种基于 Adapter 的事件引导视频帧插值方法，通过从事件流中提取图像扭曲事件（IWE）和双向稀疏光流，将其注入预训练的 Wan2.1 FLF2V（DiT 架构）扩散模型中，在几乎不改架构的前提下显著提升了大幅时间间隔帧插值的视觉质量与时间一致性。

## 研究问题与动机
- **现有 DiT 插值方法仅依赖首尾帧，导致运动模糊与结构失真**：Wan2.1 FLF2V 等基线方法只用起始帧和结束帧作为条件，当时间跨度大、运动复杂时，生成的中间帧常出现物体形变、身份不一致和结构伪影（Fig. 1）。
- **事件相机的高时间分辨率运动线索未被充分利用于 DiT 插值**：事件相机提供异步、高时间分辨率的像素级亮度变化信号，能精确捕捉复杂高速运动，但事件数据稀疏、异步，与主流生成模型所用的稠密网格表示不兼容。
- **直接端到端训练事件辅助模型需要大规模配对数据，而此类数据稀缺**：现有事件-视频配对数据集数量有限，难以支撑从头训练的端到端方案；同时 VDM-EVFI 等方法采用 ControlNet 式重型架构，计算开销大且对 DiT 模型的适配成本高。
- **如何在最小改动前提下将事件信息融入预训练 I2V 扩散模型是一个开放问题**：需要一个轻量、模块化的接入方案，使预训练模型既能利用事件的精细运动线索，又无需重新设计整个网络。

## 核心贡献（创新点）
- **提出首个基于 Adapter 的事件引导 DiT 帧插值框架，无需修改底层扩散架构**：与 VDM-EVFI 等采用 ControlNet 重型设计的方案不同，本文仅在预训练 Wan2.1 FLF2V 上附加两个轻量化插件模块，绝大部分参数保持冻结。
- **桥接事件流与扩散控制信号之间的模态鸿沟**：通过对比最大化（CMax）将原始事件流转化为与扩散模型控制信号（边缘图、光流场）语义对齐的 IWE 和双向稀疏光流，实现了事件模态与 I2V 生成管道的无缝对接。
- **设计了 IWE 编码器与光流对齐融合适配器两个插件模块**：IWE 编码器通过 3D 卷积提取边缘感知的空间结构特征并加至输入隐空间；光流对齐融合适配器在选定 DiT 块前将相邻帧特征沿双向光流 warped 并对齐后融合，为去噪过程提供显式运动一致性约束。
- **构建了目前最大规模专为事件帧插值设计的合成数据集 EvPexels**：EvPexels 包含 1,100 个多样化场景（约 390,000 帧 RGB），通过 TransNet V2 筛选运动丰富的单镜头片段，并由 Vid2e 模拟器合成事件流，将开源支持后续研究。

## 方法详解
- **总体框架**：以 Wan2.1 FLF2V（DiT 架构）为基础 I2V 模型，输入起始帧 $I_0$、结束帧 $I_1$ 及其间的事件流 $\mathcal{E}$，输出中间帧序列。模型包含事件表示模块和 Adapter 微调策略两部分。
- **事件表示——对比最大化（CMax）**：将 $I_0$ 与 $I_1$ 之间的事件流按时间分段 $[k-1, k]$，对每段应用 CMax 方法 [24,26]，计算稀疏正向光流 $\mathbf{f}_{k-1\to k}$ 及对应的 IWE $\mathcal{W}^{k-1\to k}$；反转事件流后同样计算反向光流 $\mathbf{f}_{k+1\to k}$ 与 IWE $\mathcal{W}^{k+1\to k}$，获得全序列的双向光流与边缘感知 IWE 表示。
- **IWE 编码器（空间条件注入）**：IWE 与场景边缘和物体边界强相关，通过轻量 3D 卷积网络编码为特征图 $\mathbf{F}_{\mathcal{W}}^k$，以逐元素加法方式注入到扩散模型的输入隐空间中；所有 DiT 块应用 LoRA 微调以适配新输入模态，保持参数量高效。
- **光流对齐与融合适配器（时间一致性增强）**：在每个选定 DiT 块前，将 patch-based 隐特征重排为帧级格式；利用双向光流将相邻帧（$k-1$ 和 $k+1$）的 DiT 特征 warped 至当前帧 $k$：
  $\mathbf{F}_{x_t}^{k-1\to k} = \mathrm{Warp}(\mathbf{F}_{x_t}^{k-1}, \mathbf{f}_{k\to k-1})$，$\mathbf{F}_{x_t}^{k+1\to k} = \mathrm{Warp}(\mathbf{F}_{x_t}^{k+1}, \mathbf{f}_{k\to k+1})$；
  三帧对齐特征经均值池化后通过轻量卷积融合网络得到 $\mathbf{F}_{\mathrm{fused}}^k$，以残差形式加回原 DiT 特征后重新排列回 patch token 输入 DiT 块；该模块仅插入部分 DiT 块以平衡效率与效果。
- **训练目标**：在 FLF2V 原始速度预测 MSE 损失基础上引入事件条件，整体损失形式为 $\mathcal{L} = \mathbb{E}\|u(x_t^k, \mathcal{E}, c_{\mathrm{txt}}, t; \theta) - v_t\|^2$；学习率 $1\times10^{-4}$，输入分辨率 832×480，在 8×A800 上训练 4,000 步，全局 batch size=8。

## 实验与结果
- **数据集与设置**：训练使用真实 BS-ERGB 数据集（48 个视频片段，28fps，970×625）及合成 EvPexels 数据集（1,100 视频，389,761 帧，704×480）；测试在 BS-ERGB 测试集（26 clips）、DAVIS（50 clips）和 Pexels（30 clips）上进行，统一采用 ×24 插值设置。
- **评估指标**：PSNR、SSIM、LPIPS、FID、FVD。
- **BS-ERGB 测试结果（Tab. 1）**：本文方法在感知指标上全面领先——LPIPS=0.132（最佳）、FID=8.168（最佳）、FVD=117.368（最佳）；PSNR=23.261 和 SSIM=0.704 分别排名第三和第二，优于所有扩散基线（FCVG、GI、TRF 等）。
- **DAVIS & Pexels 测试结果（Tab. 2）**：在两数据集上均取得全部五项指标的最佳结果；DAVIS 上 PSNR=25.544 / SSIM=0.799 / LPIPS=0.115 / FID=13.367 / FVD=158.557，Pexels 上 PSNR=29.089 / SSIM=0.858 / LPIPS=0.080 / FID=16.319 / FVD=151.345，相较第二好的 VDM-EVFI-Wan2.1 在 perceptual 指标上提升显著。
- **定性分析**：在 BS-ERGB 人物与篮球运动场景中，传统事件方法（TimeLens、CBMNet-Large）虽 PSNR 更高，但视觉伪影明显；本文方法利用中间事件信息准确建模动态前景运动，生成结果在时间一致性和结构保真度上更优。

## 相关工作脉络
- **Wan2.1 FLF2V [31]**：本文的基础骨干网络，基于 DiT 的 I2V 扩散模型；本文在其之上附加轻量 Adapter，而非重新训练，与之形成"参数高效微调 vs. 全量重新设计"的差异。
- **VDM-EVFI [4]**：此前最接近的工作，采用 ControlNet 式重型架构将事件体素网格编码为条件信号，需从头训练；本文方法在同等 Wan2.1 骨干下以极小参数增量达到更优效果（Tab. 5 直接对比验证）。
- **GI [32] / FCVG [38] / ViBiD [33]**：基于 SVD（U-Net）架构的扩散插值方法，未利用事件信息；本文在其基础上证明事件信号对复杂运动场景的补充价值。
- **TimeLens [29] / CBMNet-Large [13] / TimeLens-XL [20]**：传统事件引导 VFI 方法，擅长像素级重建（PSNR/SSIM 较高），但在感知质量和时间一致性上受限；本文填补了事件引导与生成式插值之间的空白。
- **TRF [6]**：将视频生成模型用于有界生成的先驱工作，但未解决帧间运动一致性问题；本文通过显式光流 warped 对齐进一步增强了时序连贯性。
- **CUBE [37]**：将事件转换为边缘图的 conditioning 方法；本文消融（Tab. 5）显示 IWE+Flow Warping 方案优于纯 Edge conditioning。

## 局限性与未来方向
- **事件提取依赖 CMax 预处理，对极端运动或低对比度场景的光流估计可能存在误差**，进而影响 warped 对齐质量；可探索端到端可微的事件处理模块。
- **EvPexels 为合成数据集**，事件由 Vid2e 模拟器生成，与真实事件相机的噪声特性存在分布差异，现实部署时的泛化能力有待进一步验证。
- **光流对齐适配器仅插入部分 DiT 块**，注入位置和数量的选择仍依赖经验调优（Tab. 4 表明前后位置各有优劣），缺乏系统性的搜索策略。
- **论文未讨论推理延迟与计算开销**，Adapter 引入的 warped 操作在高分辨率视频上的实时性尚不明确。
- **未来可扩展至更多事件驱动的视频生成任务**，如视频超分、去模糊、事件驱动的视频编辑等。

## 研究启发与可借鉴点
- **Adapter 式轻量融入策略**：将外部模态（事件/深度/分割）通过插件模块注入预训练 DiT/U-Net  diffusion 模型，而非端到端重写，是参数高效的通用范式，可迁移至其他多模态视频生成任务。
- **IWE 作为边缘-结构先验的理念**：将事件数据转化为与扩散控制信号（如 depth/edge maps）语义对齐的中间表示，比直接使用原始事件体素网格更易于被预训练模型吸收，值得在其他事件-图像联合任务中探索。
- **双向光流 warped 特征对齐机制**：在 DiT 块之间利用光流将相邻时间步特征显式对齐后再融合，是增强时间一致性的有效手段，可推广至视频生成、视频编辑等需时序连贯的任务。
- **公开合成数据集 EvPexels 的价值**：大规模高质量事件-视频配对数据是事件引导生成模型研究的关键瓶颈，开源此类数据集将持续推动领域发展。

## 关键术语表
**Event Camera（事件相机）**：异步捕获像素级亮度变化的视觉传感器，具有高时间分辨率、宽动态范围和低延迟特性，适合捕捉快速运动。
**IWE（Image Warped Events，图像扭曲事件）**：通过将事件沿光流 warped 至参考时刻生成的类边缘图像，与场景结构和运动边界高度对齐。
**DiT（Diffusion Transformer）**：基于 Transformer 架构的扩散模型，近年在视频生成领域（如 Wan2.1）展现出超越 U-Net 的性能。
**FLF2V（Frame-Level Flow Forecasting for Video）**：Wan2.1 中用于帧插值的 DiT 基础模型，以首尾帧和文本条件预测隐空间中的恒定速度向量。
**CMax（Contrast Maximization，对比最大化）**：利用事件流优化时间对齐至参考时刻以最大化图像对比度的方法，可同时估计光流和生成 IWE。
**Adapter（适配器）**：在预训练模型中插入的轻量模块化组件，以极少参数微调实现新模态或新任务的适配，保持主干参数冻结。
**LoRA（Low-Rank Adaptation）**：通过低秩分解对 Transformer/ DiT 权重进行高效微调的技术，避免全参数训练带来的计算开销。
**×24 插值**：在两个输入帧之间生成 24 倍中间帧的评估设置，用于测试大幅时间间隔插值性能。
