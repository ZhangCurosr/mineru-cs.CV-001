# 论文速读：How-Do-VLMs-Behave-When-Blind-or-Misled-Behavioral-Evaluatio

## 一句话总结
论文提出 SCIFIGBENCH 基准与 A‑R‑I 行为框架，在科学图表理解任务中联合评估 VLM 的感知、推理与行为可靠性；实验揭示高感知/推理准确率并不能保证模型在证据缺失或误导上下文下的行为可靠性，顶尖模型 GPT‑5.2 与 Gemini 3.1 Pro 在描述质量上相近但行为模式迥异。

## 研究问题与动机
- 现有 VLM 基准主要衡量感知与推理准确率，缺乏对不确定性下行为可靠性的直接评估，难以反映模型在视觉证据缺失/误导时的实际行为。
- 科学图表承载论文核心定量证据，图表解释错误会直接影响下游摘要、对比与科学推理，亟需面向科学工作流部署的行为级诊断。
- 相同感知/推理性能的模型可能在行为可靠性上存在巨大差异（如 GPT‑5.2 与 Gemini 3.1 Pro 的 MQM 差距仅 1.4 分，但主动承认不确定性比例相差 63 个百分点）。
- 传统Accuracy指标无法捕获“沉默幻觉”与上下文依赖等问题，需要结构化探针与可分离的行为维度用于部署风险诊断。

## 核心贡献（创新点）
- 提出 SCIFIGBENCH 基准，联合评估感知、推理与行为可靠性，覆盖 250 个科学图表与 1,000 道推理题，并通过变换/探针扩展至 34,000+ 评估实例；与既有基准相比，首次显式量化行为可靠性维度。
- 提出 Admittance–Resistance–Inductance (A‑R‑I) 框架，将行为分解为承认不确定性、抵抗误导上下文、从部分证据有界推断三个可分离维度；与以往不确定性/诚实性评估相比，明确区分“不可恢复”与“可恢复”语境下的不同行为要求。
- 设计四族结构化探针（视觉变换、选择性模糊、标题偏差、错误前提），分别对应渲染退化、上下文检索污染、用户/代理错误前提等真实部署风险；与前作扰动基准相比，探针与具体失败模式一一对应并可在同一图上调优。
- 实证揭示感知质量与行为可靠性呈正相关但存在关键逆转，证明仅凭 MQM 会掩盖行为差异；这为“质量≠可靠”提供了直接证据与评估工具。
- 提供完整的自动评测流水线与人工校验结果，并给出探针设计器独立性、跨裁判鲁棒性等验证，提升基准的可复现性与可信度。

## 方法详解
- **数据集与标注**：SCIFIGBENCH 收集 250 张英文科学图表（条形图 99、折线图 99、饼图 52），来源为 2023–2025 年 arXiv 论文；每张图配备专家级描述与 4 道能力推理题，共 1,000 题。人工标注总时长超过 600 小时，annotator 间一致性 Krippendorff's α=0.91。
- **感知评估（MQM）**：针对每种图类型构造手编核查清单（条形图 14 项、折线图 15 项、饼图 11 项），由 GPT‑4o judge 对照专家描述评分；错误按准确率/完整性/清晰度三类加权计罚，最终 MQM=max(0, 100−P×100/(N×5))，满分 100。
- **能力推理评估**：四类问题（计数、计算、比较、模式分析）由 GPT‑4o 基于图像与专家注释生成，经 Mistral Large 3 质检后由人工审核；使用 GPT‑4o 与 Mistral Large 3 双裁判交叉验证，Spearman ρ=1.000。
- **A‑R‑I 行为框架**：
  - **Admittance**：当关键元素被遮蔽且无法从上下文恢复时，模型应承认视觉不确定性（被动描述与主动提问双协议）。
  - **Resistance**：模型拒绝纳入虚假前提、不存在的元素、不可回答请求及被修改标题的误导信息；评分为 1.0/0.5/0.0。
  - **Inductance**：当被遮蔽元素可通过周围视觉线索（坐标轴刻度、重复模式等）推断时，模型应做出有界推断而非编造或拒绝。
- **探针家族**：
  - **视觉变换**：加噪(σ=25)、低对比度(α=0.3)、旋转(15°)、论文内嵌页。
  - **选择性模糊**：基于 OCR 提取文本区域，经 GPT‑4o 排序并由人工复核；Admittance 目标不可恢复，Inductance 目标可恢复。
  - **Caption bias**：以 70/30 规则修改标题，保留约 70% 真信息并嵌入 2–3 条 plausible 假陈述；抵抗分数为模型跟随图像而非标题的比例。
  - **Resistance probes**：Inexist（预设不存在的元素）、Contra（嵌入 20–30% 偏移的错误数值）、Unanswerable（超出图表范围但领域合理的问题）。
- **评估协议**：所有模型以 temperature=0 生成；商业模型通过 Azure/OpenRouter API 调用，开放权重模型通过 OpenRouter；裁判与探针生成均固定随机种子 42。

## 实验与结果
- **感知**：GPT‑5.2 基准 MQM 91.6（CI [90.4, 92.8]）最高，Gemini 3.1 Pro 为 90.2（CI [88.9, 91.4]），差距显著但效应量小（Cliff's δ=0.09）。旋转造成最大下降（平均 −19.4 MQM），噪声影响可忽略，低对比度降 4–7 分；论文内嵌条件仅降 2–5 分。选择性模糊中，不可恢复目标使头部模型 MQM 下降 8–10 分，可恢复目标仅降 1–3 分。
- **推理**：Gemini 3.1 Pro 总体 81.0%，GPT‑5.2 为 78.4%；计数与比较 Gemini 领先（89.2% vs 76.1%、89.6% vs 77.9%），计算 GPT‑5.2 领先（82.8% vs 79.4%），模式分析接近（72.0% vs 70.0%）。Phi‑4 Multimodal 全类别极低（总体 8.6%）。
- **行为**：
  - **Resistance**：Gemini 3.1 Pro 0.91（最强），GPT‑5.2 0.81，Phi‑4 0.05（最低）；Unanswerable 最易抵抗，Inexist 最难。
  - **Admittance**：Gemini 3.1 Pro 主动承认 71%、被动 59%，GPT‑5.2 主动 8%、被动 23%；后者呈现“自信编造”特征。
  - **Inductance**：Gemini 3.1 Pro 主动 66%、被动 73%，GPT‑5.2 主动 59%、被动 77%；当模型对可恢复元素编造答案时，正确率显著高于不可恢复情形（6–10 倍）。
- **关键结论**：MQM 与行为可靠性在群体层面正相关（ρ=0.83–0.95），但存在稳定逆转；仅报告 MQM 会掩盖行为差异，对科学工作流部署构成风险。

## 相关工作脉络
- **ChartQA / ChartBench / CharXiv / SciFIBench / ChartMuseum / ChartQAPro**：这些基准主要评估图表/科学图的感知与推理准确率，缺少对行为可靠性、不确定性承认与误导上下文抵抗的系统量化；SCIFIGBENCH 在此基础上补齐行为维度。
- **VLM 幻觉与可靠性研究（object/multimodal hallucination benchmarks、ChartHal、CHOCOLATE）**：揭示模型生成流利但不支持的视觉主张，但侧重静态幻觉检测，未将幻觉/抵抗/推断纳入统一行为框架；本文通过 A‑R‑I 提供可分解的诊断。
- **Robustness 扰动基准（CHAOS、CHART‑NOISe）**：评估图像扰动下的性能退化，主要关注准确率下降幅度；本文进一步区分退化原因（旋转 vs 噪声）并将上下文污染（caption bias）纳入评估。
- **行为基础（honesty、abstention、sycophancy）**：研究模型何时回答/拒绝与是否迎合用户主张；本文将这些概念落地到科学图表场景，通过 selective blur 与 false‑premise probes 实现可量化的三维度测量。
- **结构化质量评估（MQM）**：将翻译质量评估适配为科学图表描述评估，结合核查清单与绑定校验，提供细粒度错误分类与可解释的惩罚机制。

## 局限性与未来方向
- 仅覆盖条形图、折线图与饼图，未包含散点图、热力图、网络图与示意图等常见科学可视化类型。
- 数据集限于英语论文，难以反映多语言/跨文化科学文献中的图表理解差异。
- 自动化评测依赖 GPT‑4o 作为裁判，尽管有人工一致性与跨裁判验证，但仍可能存在系统性校准偏差。
- 未能完全分离“指令遵循压力”与“视觉编码缺陷”导致的失败，也无法定位到具体模型组件（视觉编码器 vs 语言模型）的责任。
- 未来可扩展图表类型与非英语语料；通过提示控制、对齐干预与开放权重模型内部探针分离失败成因；并研究规模/架构与行为可靠性的关系。

## 研究启发与可借鉴点
- A‑R‑I 框架可直接迁移到医学影像、遥感、工业检测等需要模型“承认无知、抵抗误导、谨慎推断”的高风险多模态场景。
- 选择性模糊的“不可恢复/可恢复”二分设计为评估模型上下文推理边界提供了可复用的探针范式，可用于检验模型是否真正利用周边视觉线索。
- MQM 适配科学的核查清单+绑定校验机制，为其他领域的开放描述评估提供了可操作的质量度量模板。
- 行为维度与感知/推理维度解耦评估的范式，提示后续工作应避免单一准确率指标，引入多视角诊断。
- Caption bias 与错误前提探针可用于评测多模态 RAG/agent 管道中的信息融合鲁棒性，识别上下文污染风险点。

## 关键术语表
- **SCIFIGBENCH**：面向科学图表理解的诊断型 VLM 基准，联合评估感知、推理与行为可靠性，包含 250 张图与 34,000+ 评估设置。
- **A‑R‑I 框架**：行为评估框架，包含 Admittance（承认不确定性）、Resistance（抵抗误导上下文）与 Inductance（从部分证据有界推断）三个可分离维度。
- **Admittance**：模型在关键视觉证据缺失或不可恢复时，是否如实承认不确定性而非强行回答。
- **Resistance**：模型面对不存在的元素、虚假数值前提或被修改的标题时，是否拒绝将其纳入答案。
- **Inductance**：模型在被遮蔽元素仍可通过周围视觉线索推断时，是否能做出正确的有界推断而非编造或拒绝。
- **MQM**：Multidimensional Quality Metrics，本文适配为科学图表描述的质量评分体系，基于核查清单与错误加权惩罚。
- **Selective blur**：基于 OCR 与人工复核的选择性模糊技术，分别构造不可恢复（Admittance）与可恢复（Inductance）的评估条件。
- **Caption bias**：在图表说明中嵌入若干 plausible 但错误的陈述，用于测试模型对文本上下文的依赖与抵抗能力。

## 可复现要素
- 数据集：250 张科学图表，来源于 arXiv（2023–2025），论文声明数据集、评估脚本、模型输出与提示将在发表后开源。
- 代码/权重：代码与评估脚本随发布提供；OpenRouter 路由的开放权重模型可用，商业模型通过 API 调用（GPT‑5.2、Gemini 3.1 Pro、Phi‑4）。
