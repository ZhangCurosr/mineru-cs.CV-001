# 论文速读：CoverPrune-Coverage-Driven-Token-Pruning-for-3D-VLMs-via-Opt

## 一句话总结
本文提出 CoverPrune，一种针对 3D VLM 的免训练 Token 剪枝框架，将剪枝目标从传统的“特征多样性最大化”重构为“视觉证据覆盖度最大化”，通过最优传输（Optimal Transport, OT）理论联合建模特征、3D 几何与时间顺序，在激进压缩下仍能保持卓越的空间推理性能。

## 研究问题与动机
1. **3D VLM 推理算力瓶颈**：多帧/多视角输入使视觉 Token 数量激增至数百甚至数千，导致注意力计算与 KV Cache 开销呈二次方增长，成为实际部署的核心瓶颈。
2. **现有剪枝方法的错位**：主流免训练剪枝依赖早期注意力打分或特征空间多样性筛选，这些启发式策略针对 2D 粗粒度理解设计，未显式建模 3D 几何结构与多视角一致性。
3. **多样性导向的致命缺陷**：在 3D 场景中，同类物体的多视角观测 Token 在特征空间高度相似，多样性剪枝会优先剔除代表性强、重复出现的原型 Token，转而保留离群点，破坏空间关系推理所需的几何证据。
4. **目标函数缺失**：缺乏同时衡量语义对齐、空间邻近与时间连贯性的统一覆盖度量，导致在低保留率（如 10%、5%）下推理性能断崖式下降。

## 核心贡献（创新点）
1. **剪枝范式重构**：首次将 3D VLM Token 剪枝从“最大化分散度”转向“最大化覆盖度”，利用 OT 将子集选择形式化为最小化表征失真问题，从根本上纠正多样性策略的偏差。
2. **FST 联合代价与信息感知容量**：设计 Feature-Spatial-Temporal (FST) 传输代价，显式融合特征余弦距离、3D 欧氏距离与时间相对顺序；提出基于局部独特性的动态目标容量机制，使信息密集的几何/时序 Token 获得更高覆盖权重。
3. **SGS 贪心优化算法**：针对 OT 子集选择的 NP-hard 特性，采用半松弛 OT（Semi-Relaxed OT）保证目标函数的单调次模性，并结合空间邻域限制设计 SGS 算法，避免每步迭代的全局重算。
4. **CoverPrune-Lite 分块近似**：基于 Morton 码空间填充曲线实现 3D 感知确定性排序，将全局 OT 求解退耦为 K 个独立块内单次加权匹配，将剪枝复杂度降至 O(N log N)，实现极低开销的在线加速
