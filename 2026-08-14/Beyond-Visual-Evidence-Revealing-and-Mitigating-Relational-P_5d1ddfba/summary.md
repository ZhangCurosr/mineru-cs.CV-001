# 论文速读：Beyond-Visual-Evidence-Revealing-and-Mitigating-Relational-P

## 一句话总结
本文揭示了文档图像多模态大语言模型（MLLMs）在关键信息提取（KIE）任务中的**关系级隐私泄露**风险——当视觉证据不足时，模型会依赖训练中记忆的字段时间系关联，联合生成多个敏感字段；并提出**动态关系遗忘框架（DRUF）**，通过关系解耦遗忘（RDU）与动态遗忘集合更新机制，在抑制泄露的同时保持KIE能力。

## 研究问题与动机
- **核心问题**：文档图像MLLM在KIE任务中，当输入图像缺乏有效视觉证据（空白/噪声/无关图像）时，模型并非仅泄露单一敏感字段，而是倾向于**联合生成多个相关敏感字段对**（如姓名+证件号同时出现），形成关系级隐私泄露。
- **现有方法不足1**：已有MLLM隐私研究多关注单一属性泄露或通用视觉-语言场景，忽视了文档KIE任务中**结构化字段相关性**带来的联合泄露风险。
- **现有方法不足2**：现有机器学习遗忘方法依赖预定义的静态遗忘集，假设遗忘目标为独立概念；但文档KIE的泄露风险涉及整个训练集中的敏感字段对，且泄露目标随模型行为动态变化，静态方法难以有效追踪。
- **现有方法不足3**：缺乏专门针对文档图像MLLM在视觉证据缺失条件下**关系级隐私泄露**的系统评测基准。

## 核心贡献（创新点）
- **发现关系级隐私泄露新风险**：首次系统揭示文档理解MLLM在弱视觉证据下依赖训练记忆联合生成敏感字段对的隐私风险，与以往单一字段泄露研究形成本质区别。
- **提出DRUF动态关系遗忘框架**：通过关系解耦遗忘（RDU）直接以敏感字段对为遗忘单元（而非单字段或整样本），并利用动态遗忘集合持续追踪当前模型的实际泄露行为，与静态遗忘方法形成本质差异。
- **设计乘性KL耦合遗忘目标**：将两个敏感字段的span级KL散度相乘构成遗忘损失 $L_{\text{forget}} = -K_a K_b$，直接抑制字段的联合可恢复性，区别于独立字段级或样本级遗忘策略。
- **构建DocPrivacyBench评测基准**：提出Image-Driven和Prompt-Driven两种评测模式，包含NIQP/SIEP/ECAP三类提示探针，系统评估文档MLLM的关系级隐私泄露与隐私-效用权衡。

## 方法详解
- **整体架构**：DRUF包含Retain（保留）分支与Forget（遗忘）分支，总损失为 $L = L_{\text{retain}} + \lambda L_{\text{forget}}$。
- **Retain分支**：将正常文档样本同时输入冻结的教师模型和可训练的学生模型，通过教师-学生对齐损失 $L_{\text{retain}}$ 保持学生的KIE能力不被破坏。
- **动态遗忘集合构建**：每轮探测时使用空白图像（无有效视觉证据）作为输入，固定提示语，检测当前学生模型实际泄露的敏感字段对，构成本轮动态遗忘集 $F^{(t)} = \{(s_a, s_b) \mid (s_a, s_b) \text{在当前探测中被检测到泄露}\}$。每隔 $\Delta$ 步重新评估并更新遗忘集合，以追踪模型泄露行为的变化。
- **关系解耦遗忘（RDU）**：对检测到的每个敏感字段对 $r_i^{a,b} = (s_a^i, s_b^i)$，计算两个字段在span级别的KL散度 $K_a = \text{KL}_{\text{span}}(s_a^i)$ 和 $K_b = \text{KL}_{\text{span}}(s_b^i)$，其中 $\text{KL}_{\text{span}}(s) = \frac{1}{n-m+1}\sum_{j=m}^{n} \text{KL}(p_T^j(\cdot|c,y_{<j}) \| p_S^j(\cdot|c,y_{<j}))$。遗忘损失为两者的乘积：$L_{\text{forget}} = -K_a K_b$，梯度为 $\frac{\partial L_{\text{forget}}}{\partial K_a} = -K_b, \frac{\partial L_{\text{forget}}}{\partial K_b} = -K_a$，实现字段对的耦合抑制。
- **关键设计原则**：使用空白图像隔离视觉接地信号，确保遗忘针对的是记忆驱动的联合生成行为；动态更新机制避免静态集合导致的漏报或过度遗忘。

## 实验与结果
- **数据集**：DocXPand-25k（含噪声的低质量身份证/护照数据）、IDNet（高质量驾驶证数据）、IDNet(with noise)（添加噪声的IDNet）。
- **评估模型**：LLaVA-1.5-hf、Xgen-Phi3、Idefics2，分别在三种数据集上各训练5000样本。
- **基线方法**：GA、GA+KL、SCRUB、DPO、FTF、DP（共6种遗忘方法）。
- **主要结果**：
  - 基础模型普遍存在严重泄露：LLaVA-1.5-hf在DocXPand-25k Image-Driven设置下Acc@1.0高达0.835，而Idefics2仅为0.189；低质量/含噪声数据导致更高泄露风险。
  - DRUF在双敏感字段（姓名+证件号）设置下，Prompt-Driven泄露准确率降至**0.000**，Image-Driven降至**0.001**，优于最强基线SCRUB（0.029/0.049），提升**4.8个百分点**。
  - DRUF在KIE任务上保持LC=**0.808**，显著优于GA（0.119）和GA+KL（0.0259），与SCRUB（0.837）接近。
  - 泄露对数量：Base模型Image-Driven泄露62对，DRUF仅5对，远低于DPO（78）、FTF（90）、SCRUB（34）。
  - 消融显示：动态遗忘集优于静态集（静态集在500步后KIE LC降至0.055）；乘性耦合优于NPO/LEGO/CU/RF-Entangle等替代方案；$\gamma=3$为最优采样比例。

## 相关工作脉络
- **Multi-PA / MM-Privacy**：指出多模态大模型隐私评估的维度不完整性，本文在此基础上聚焦文档KIE场景的关系级泄露，填补结构化隐私风险分析的空白。
- **PrIeD-KIE**：首次揭示文档KIE任务的隐私泄露风险，但缺乏针对性的隐私增强方法与微调指南，本文直接回应此缺口。
- **GA / SCRUB**：传统机器学习遗忘方法，GA直接梯度上升擦除知识但损害效用；SCRUB通过教师-学生对齐平衡遗忘与保留，但依赖静态遗忘集且无法精准抑制字段对联合生成，本文方法在此基础上引入动态追踪与关系耦合。
- **SIU / MultiDelete**：多模态遗忘方法，聚焦单个视觉概念的记忆删除，不适用于文档场景中跨字段关联的隐私风险。
- **DPO / FTF / DP**：偏好优化、随机标签微调、差分隐私等方法，在抑制联合泄露方面效果有限，本文通过关系级目标实现更彻底的控制。

## 局限性与未来方向
- **局限性**：
  - 实验仅在三种文档类型（身份证、驾驶证、护照）和三个开源MLLM上验证，泛化到更广泛的文档场景（如票据、表格）尚待检验。
  - 动态遗忘集合的更新频率（$\Delta$）和测试集大小对隐私-效用权衡有显著影响，最优超参依赖具体任务设定。
  - 关系级遗忘主要针对预定义的敏感字段对（姓名+证件号），对更多字段组合（如姓名+地址+生日三重泄露）的泛化能力未充分验证。
- **未来方向**：
  - 扩展至更多文档类型和跨语言场景。
  - 探索更高效的动态更新策略以减少评估开销。
  - 研究更复杂的多元字段联合泄露模式及其抑制方法。
  - 将关系级隐私分析框架迁移至其他结构化信息提取任务。

## 研究启发与可借鉴点
- **动态遗忘集合思想**：将"当前模型实际泄露行为"作为遗忘目标而非预设静态集合，这一自适应思路可迁移至其他需要对抗模型行为变化的隐私保护场景。
- **乘性耦合损失设计**：通过相乘两个子目标的KL散度来实现"联合抑制"，区别于独立求和或最大操作，为多变量耦合遗忘提供了一种新的优化范式。
- **双模式评测设计**：Image-Driven与Prompt-Driven分离评估，以及三类提示探针（NIQP/SIEP/ECAP）的精细化设计，为文档MLLM隐私评测提供了可复用的实验协议。
- **教师-学生保留机制**：在遗忘过程中通过冻结教师模型对齐学生行为，有效缓解了传统遗忘方法效用骤降的问题，可与本团队的方向结合用于增强模型鲁棒性。

## 关键术语表
- **关系级隐私泄露（Relational Privacy Leakage）**：模型在视觉证据不足时联合生成多个相关敏感字段（如姓名+证件号同时出现）的隐私风险。
- **关键信息提取（KIE, Key Information Extraction）**：从文档图像中提取结构化字段（如姓名、证件号、出生日期等）的任务。
- **动态遗忘集合（Dynamic Forget Set）**：通过定期探测当前模型的泄露行为来更新遗忘目标的集合，而非预先静态定义。
- **关系解耦遗忘（RDU, Relational Decoupling Unlearning）**：以敏感字段对为基本遗忘单元，通过乘性KL耦合抑制联合生成的遗忘方法。
- **DocPrivacyBench**：本文提出的用于系统评估文档图像MLLM在视觉证据缺失条件下关系级隐私泄露的基准测试。
- **Image-Driven / Prompt-Driven**：两种评测模式，分别通过空白图像触发和多样化文本提示触发隐私泄露。
- **KL_span（Span-level KL Divergence）**：教师与学生模型在敏感字段token区间上的平均分布散度，衡量遗忘强度。
- **泄露准确率（ACC）**：检测模型输出是否包含与训练数据匹配的敏感字段对的准确率指标。

## 可复现要素
- **数据集**：DocXPand-25k（公开）、IDNet（公开）；论文使用了基于这两个数据集构建的DocPrivacyBench，IDNet(with noise)为自行构造的加噪版本。
- **代码/权重**：论文声明代码和基准已开源，链接为 https://github.com/xubeining/Beyond-Visual-Evidence
- **关键超参**：学习率 $1 \times 10^{-4}$，batch size=8，AdamW优化器，15 epochs；遗忘-保留采样比 $\gamma=3$（默认）；探测评估间隔 $\Delta=5$（每500步更新一次遗忘集）；测试集大小为100时达到最佳平衡。
