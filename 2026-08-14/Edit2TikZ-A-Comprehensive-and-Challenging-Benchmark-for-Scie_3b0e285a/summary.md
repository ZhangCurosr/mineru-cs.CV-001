# 论文速读：Edit2TikZ-A-Comprehensive-and-Challenging-Benchmark-for-Scie

## 一句话总结
论文提出了 **Edit2TikZ**，一个包含 1,548 个样本的综合基准测试，用于系统评估多模态大语言模型（MLLMs）通过生成可编译 TikZ 代码来编辑科学图表的能力；并构建了对齐人类的评估框架（RS/ECS），证明现有模型在该任务上仍不可靠，最后通过两阶段课程学习（TikZEditMix）显著提升了紧凑型模型（Qwen3.5-4B）的性能。

## 研究问题与动机
1. **现有基准缺乏对“编辑”任务的系统性评估**：已有的 TikZ 基准（如 DeTikZify, TikZero, GeoTikzBridge）主要关注从图像到代码的重建或生成，无法测试模型在修改指定内容的同时保留其余图表内容的能力。
2. **图表编辑基准局限于绘图库图形**：Chart-editing 类基准（如 ChartEdit）主要针对条形图、折线图等绘图库生成的图表，无法覆盖几何图解、电路图、模型架构图等通用科学图表。
3. **端到端科学图表编辑具有更高复杂度**：模型需联合完成视觉结构恢复、指令接地（grounding）、代码生成以及无关内容保持（preservation），这对 MLLMs 提出了比单纯重建更严苛的要求。
4. **紧凑模型在此任务上表现严重不足**：开源小参数模型（<9B）在指令遵循和完整代码生成上存在显著短板，亟需专用数据与训练策略的提升。

## 核心贡献（创新点）
1. **提出 Edit2TikZ 基准测试**：构建了包含 1,548 个样本的科学图表编辑数据集，涵盖真实世界样本与控制合成样本，支持文本与视觉定位请求，并包含多步编辑及步骤级标注。
   * *区别*：不同于仅评估重建的 DeTikZify 或仅关注绘图图表的 ChartEdit，本文聚焦于“指令引导的、可编译代码的科学图表端到端编辑”。
2. **定义原子操作与结构化编辑单元**：将编辑任务分解为 8 种原子操作（外观更新、离散形式更新、元素插入/删除、度量参数更新、引用绑定更新、空间布局更新、文本符号更新），并为每个样本提供步骤级标注。
   * *区别*：现有基准多缺乏细粒度的操作步骤分解与原子操作类型的系统定义。
3. **构建人类对齐的评估框架（RS 与 ECS）**：提出 RestorationScore（RS）评估非目标内容的保持，EditCorrectnessScore（ECS）评估编辑单元的完成情况，二者均经人工标注验证并与 AI Judge（GPT-5.6-Terra）高度一致。
   * *区别*：超越了仅依赖 cBLEU/TED 代码相似度或 DSim 图像感知距离的传统指标，直接测量“编辑是否完成”与“无关内容是否保留”。
4. **构建 TikZEditMix 并验证课程学习有效性**：结合重建与编辑数据构建混合训练集，采用“先重建、后编辑”的两阶段课程学习，使 Qwen3.5-4B 的编译成功率从 45.35% 提升至 83.40%，平均指标提升 18.7 分。
   * *区别*：证明了单一阶段训练不如分阶段课程学习，且重建能力是编辑性能的关键瓶颈。

## 方法详解
1. **任务定义**：
   - 样本表示为元组 $(I_s, q^{\text{text}}, q^{\text{vis}}, y^*, I_t, E)$，其中 $I_s$ 为源图，$q^{\text{text}}$ 为文本指令，$q^{\text{vis}}$ 为可选的视觉定位提示（半透明红色框），$y^*$ 为黄金编辑代码，$I_t$ 为渲染结果，$E$ 为编辑步骤序列。
   - 模型输入为 $I_s \oplus q^{\text{vis}}$ 与 $q^{\text{text}}$，输出可编译 TikZ 代码 $\hat{y}$。
2. **数据构建流程**：
   - **真实世界编辑**：从同一论文中提取结构相似但细节不同的图表对，通过指令生成模型生成指令，编辑单元标注模型分解为原子操作，人工校验。
   - **控制合成编辑**：对未使用的源图，由规划器生成指令与编辑单元，编辑模型应用编辑得到候选目标代码，经确定性检查与多模态验证器筛选，失败样本可获反馈并最多重试两次。
   - **视觉定位提示**：当文本无法明确区分相似元素时，规划器生成对应区域的红色框叠加于源图。
3. **评估指标**：
   - **编译成功率（Compilation Success Rate）**：代码能否在 TeX Live 环境中成功编译渲染。
   - **cBLEU & TED**：代码层面的 token 重叠与结构距离（沿用 DeTikZify）。
   - **DSim**：基于 DreamSim 的预测渲染与黄金渲染的感知距离。
   - **RS（RestorationScore，0-100）**：评估非目标内容保持，细分为文本/样式（30分）、对象/关系（30分）、布局/尺度（40分）。
   - **ECS（EditCorrectnessScore，0-100）**：评估每个编辑单元的完成度，分为 0/40/80/90/95/100 六个等级，样本级为所有单元平均分。
   - *主错误规则*：同一底层故障不在多个维度重复扣分。
4. **训练方法（TikZEditMix）**：
   - 数据集：32,448 个样本，含 20,244 个重建样本（来自 DaTikZ-v3）与 12,204 个编辑样本。
   - **Stage 1（重建）**：最小化 $\mathcal{L}_{\text{rec}}(\theta) = -\sum_t \log p_\theta(y_t \mid I, y_{<t})$，学习从图像到 TikZ 代码的映射。
   - **Stage 2（编辑）**：最小化 $\mathcal{L}_{\text{edit}}(\theta) = -\sum_t \log p_\theta(y_t^* \mid I_s, q, y_{<t}^*)$，学习在源图与指令下生成编辑后代码。
   - 超参：Stage 1 学习率 $10^{-5}$，Stage 2 学习率 $5 \times 10^{-6}$，各训练 1 epoch，8×A800 GPU。

## 实验与结果
1. **基线模型**：14 个主流 MLLMs，包括 8 个闭源（Qwen3.7-plus, Doubao-Seed-2.1-Pro, GPT-5.6 系列, Claude 系列, Gemini-3.1-Pro）与 6 个开源（Qwen3.5 系列 2B/4B/9B, Qwen3.6-27B, Gemma-4-E2B/E4B-it）。
2. **主要结果**：
   - 闭源模型平均编译成功率 **75.15%**，RS 58.76，ECS 59.80；开源模型平均编译成功率仅 **39.95%**，RS 23.49，ECS 21.99。
   - 最强闭源模型 **Gemini-3.1-Pro** 编译成功率 **88.37%**，RS 74.51，ECS 75.02，但仍约有 12% 样本失败。
   - 开源模型随规模增大性能提升：Qwen3.5 从 2B 到 27B，编译成功率从 13.24% 升至 69.77%，RS 从 6.09 升至 48.57。
3. **关键发现**：
   - 代码相似度（cBLEU/TED）与编辑质量（ECS）相关性弱，相同 cBLEU 的模型 ECS 可能相差 27 分。
   - 紧凑模型（≤9B）的主要失败模式是**程序不完整**（77.1% 的 2B 失败样本结构不完整），源于重复生成与长程序终止困难。
   - 更好的重建能力不自动带来更好的编辑能力：Qwen3.5-9B 比 4B 重建更好，但 ECS 在编译成功样本中反而略降。
   - 不同原子操作难度差异大：**离散形式更新、空间/分层更新、引用/绑定更新、度量/参数更新** 最难，而 **文本/符号更新与元素删除** 相对简单。
4. **课程学习结果（Table 5）**：
   - **Qwen3.5-4B**：两阶段课程学习使编译成功率从 45.35% 提升至 **83.40%**，RS 从 26.10 提升至 48.72，ECS 从 22.54 提升至 37.32，平均提升 18.7 分；且优于同等数据量的单阶段训练。
   - **Qwen3.5-2B**：编译成功率从 13.24% 提升至 69.77%，但 Stage 2 增益有限（Comp. +2.39, ECS +5.01），显示小模型接近容量上限。
5. **外部重建基准（DaTikZv2）**：经过两阶段训练的 Qwen3.5-4B 在 DaTikZv2 上取得最佳 cBLEU（4.215）与 DSim（73.189），超过使用 ~360K 数据微调的 DeTikZify 模型。

## 相关工作脉络
1. **DeTikZify (2024)**：从科学图表与草图重建 TikZ 代码，专注重建任务，不支持指令编辑。
2. **TikZero (2025)**：文本引导的 TikZ 生成，侧重零样本生成，非编辑场景。
3. **GeoTikzBridge (2026)**：面向几何图形的 image-to-TikZ 监督，覆盖范围仅限几何领域。
4. **vTikZ (2025)**：支持少量编辑的 TikZ 基准，但仅 100 个样本，无多步编辑与视觉定位提示。
5. **ChartEdit (2025)**：针对绘图库图表（如 Matplotlib）的编辑基准，覆盖条形图、折线图等，无法评估几何图、电路图等通用科学图表。
6. **SVGEditBench V2 (2025) / VCG-Bench (2026)**：支持 SVG 代码编辑或统一视觉生成与编辑，但前者聚焦 SVG，后者编辑协议基于代码条件，与本文的图像到可编译 TikZ 编辑任务不同。

## 局限性与未来方向
1. **数据集规模有限**：Edit2TikZ 仅 1,548 个样本，对于预训练或大规模微调而言体量较小。
2. **小模型提升接近瓶颈**：Qwen3.5-2B 在 Stage 2 编辑训练后增益有限，表明更小容量模型可能已触及性能天花板。
3. **复杂关系编辑仍具挑战性**：涉及密集点-边关系、多子图或精确几何保持的编辑，当前模型（包括闭源强模型）仍有较高失败率。
4. **评估框架依赖 AI Judge**：虽经人工验证具有良好对齐性，但 RS/ECS 的最终评分由 GPT-5.6-Terra 执行，可能存在与人工评分的潜在偏差。
5. **未来方向**：可扩展至更多图表类型（如三维图、动态图）、探索更高效的编辑协议（如结合 agentic 迭代 refine）、研究重建与编辑能力的解耦与协同训练机制。

## 研究启发与可借鉴点
1. **原子操作分解与步骤级标注**：将编辑任务分解为 8 种原子操作并提供步骤级标注，为细粒度评估提供了可复用的范式，可迁移至其他代码生成或视觉编辑基准。
2. **双维度评估框架（RS+ECS）**：分离“编辑完成度”与“无关内容保持度”的评估思路，解决了传统图像相似度指标（如 DSim）无法捕捉功能性错误的缺陷，值得在图像编辑、文档编辑等任务中借鉴。
3. **课程学习策略（Reconstruction-then-Editing）**：先训练图像到代码的重建能力，再微调指令编辑能力，两阶段策略显著提升了紧凑模型性能，该思路可推广至其他“理解-生成-编辑”链路任务。
4. **视觉定位提示（Visual Localization Prompt）**：引入半透明覆盖框作为可选输入，帮助模型精确定位编辑区域，降低了纯文本指令在多相似元素场景下的歧义，可用于其他 grounded editing 任务。
5. **失败模式分析驱动的数据筛选**：通过分析编译失败、结构不完整、重复生成等失败模式，可指导合成数据的构造与过滤，提升训练数据质量。

## 关键术语表
**Edit2TikZ**：论文提出的综合科学图表编辑基准测试，包含 1,548 个样本，支持文本与视觉定位指令的端到端 TikZ 代码编辑评估。
**TikZ**：LaTeX 中用于绘制矢量图形的标记语言，常用于科学图表。
**RestorationScore (RS)**：评估编辑后图表中非目标内容（文本、样式、对象、关系、布局）保持程度的指标，满分 100。
**EditCorrectnessScore (ECS)**：评估每个编辑单元完成情况的多级评分指标，满分 100，反映编辑指令的执行准确度。
**Atomic Operation**：八种基本编辑操作类型，包括外观更新、离散形式更新、元素插入/删除、度量参数更新、引用绑定更新、空间布局更新、文本符号更新。
**TikZEditMix**：论文构建的混合训练数据集，包含 32,448 个样本，由 20,244 个重建样本与 12,204 个编辑样本组成。
**Reconstruction-then-Editing Curriculum Learning**：两阶段课程学习策略，第一阶段学习图像到 TikZ 的重建，第二阶段学习指令条件的图表编辑。
**GPT-5.6-Terra**：论文选定的 AI Judge 模型，在 RS 与 ECS 评估中与人工评分具有最高一致性（MAE 最低，相关系数最高）。

## 可复现要素
- **数据集**：Edit2TikZ 基准测试数据将开源（https://github.com/Solunny/Edit2TikZ），包含 1,548 个样本；TikZEditMix 训练集也将随代码一起发布。
- **代码**：项目代码与数据将于 GitHub 开源。
- **权重**：论文未提及开源模型权重，仅报告了 Qwen3.5-2B/4B 在课程学习前后的实验结果。
- **关键超参**：Stage 1 学习率 $10^{-5}$，1 epoch；Stage 2 学习率 $5 \times 10^{-6}$，1 epoch；硬件 8×A800 GPU；输出编译后最大长边 1,024 像素。
- **评估环境**：共享 TeX Live 环境编译，前景裁剪后 resize 至最大长边 1,024 像素。
