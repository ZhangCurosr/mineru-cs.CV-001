# 论文速读：H2R-Bench: Benchmarking Human-to-Robot Manipulation Video Generation in World Models

## 一句话总结
论文提出 H2R-Bench，一个面向**跨身体形态人类到机器人操作视频生成**的基准测试，通过5个维度系统化评估视频世界模型能否在保持源操作意图与交互证据的前提下，将第一人称人类示范视频转化为指定机器人形态的操作视频。

## 研究问题与动机
- **机器人演示数据收集成本高**，而第一人称人类操作视频丰富且蕴含丰富的对象 affordance 与交互意图，但直接跨形态迁移因人类手与机器人末端执行器差异而困难。
- **现有视频生成基准**（如 VBench、WorldModelBench）主要评估整体视觉合理性与时序一致性，无法诊断人类到机器人转移特有的失败模式（如错误形态替换、源操作证据丢失）。
- **视频世界模型作为跨形态桥梁**的能力尚未被系统评估，模型生成的视频可能在视觉上合理，但并未真正保留源视频的任务目标、动作事件与功能交互证据。
- **缺乏源条件化的跨形态评测协议**，现有工作多基于文本或机器人-centric 状态生成，未考察"给定具体人类示范视频+指定形态"这一更严格的设定。

## 核心贡献（创新点）
1. **提出源条件化人类到机器人视频转移评测设定**：要求生成视频在保留特定源示范的任务目标与功能交互的同时，用指定机器人形态替换人类操作者，而非仅生成视觉合理的机器人视频。
2. **构建 H2R-Bench 基准**：覆盖6类操作家族（刚性物体重排、机构驱动、插入装配、变形物体配置、散料转移、表面/材料变换）与2种目标形态（平行夹爪、灵巧手），包含120个源视频×2种形态共240个转移案例及人工验证的结构化标注。
3. **设计转移感知多维度评估协议**：独立评估目标状态完成（M1）、动作事件完成（M2）、功能接触转移（M3）、身体形态正确性（M4）与通用视频质量（M5），揭示当前模型视觉质量与有效机器人转移之间的持续错配。
4. **建立三评委 MLLM 自动评分与人工验证对齐的评估管道**：H2RCore 加权聚合（接触与形态各占30%），与人工评分的聚合 Pearson r=0.930，内部场景 Spearman ρ=0.883，证明自动化评估的有效性。

## 方法详解
- **基准构建**：从 EgoDex test split 选取120个5秒第一人称操作片段，按任务物理状态变化分为6类（F1–F6）；每个片段与两种目标形态（parallel-jaw gripper、dexterous hand）配对，生成240个评估实例。
- **结构化标注**：使用 Qwen3.7-Plus 从源视频中提取初始/最终状态、操作对象与工具、所需动作事件、接触证据及形态适配策略；所有标注经人工核对修正后使用。
- **原生接口生成协议**：11个模型（5个闭源、6个开源）分别以其最强公开条件化接口接收输入——视频条件模型接收完整源片段，帧条件模型接收按时间顺序的源帧；统一任务与形态提示词，主实验中不使用目标机器人参考图像。
- **五维评估体系**：
  - **M1 目标状态完成**：评估最终状态谓词（空间关系、机构状态、附着、变形等）的加权满足程度，25帧采样。
  - **M2 动作事件完成**：评估抓取、插入、释放、倾倒、擦拭等所需动作事件是否可见执行，不要求姿态/轨迹模仿。
  - **M3 功能接触转移**：对比源视频25帧与生成视频25帧，评估接触区域、接触建立、操作模式、时序支撑的对象响应、形态兼容策略；源场景/实体替换为硬失败。
  - **M4 身体形态正确性**：评估机器人存在、人类手部消失、形态类别匹配、末端执行器正确、时序结构一致；无机器人或人类执行主操作为硬失败。
  - **M5 视频质量**：独立于任务的客观指标，聚合 MUSIQ 成像质量、CLIP-based 审美质量、时序稳定性与 AMT-S 插值运动平滑度。
- **H2RCore 聚合**：`H2RCore = 100 × (0.15·S_goal + 0.15·S_action + 0.30·S_contact + 0.30·S_emb + 0.10·S_video)`，强调接触与形态各占30%，视频质量仅占10%。

## 实验与结果
- **数据集**：120个 EgoDex 源视频，6类操作任务×2种目标形态，共240个转移案例。
- **评测模型**：11个最新视频生成模型（Seedance 2.0、Wan2.7、Kling-V3、Veo 3.1、Grok Imagine Video、HunyuanVideo 1.5-I2V、LTX-2.3、Mitty-EPIC14B、SkyReels-V3-R2V、LongCat、Wan2.2）。
- **最强结果**：Seedance 2.0 在两种形态下均取得最高 H2RCore——**平行夹爪 77.3**、**灵巧手 84.6**；Wan2.7 紧随其后（76.5 / 83.1）；Kling-V3 位列第三（74.5 / 81.7）。
- **关键发现**：
  - 视频质量（M5）与 H2RCore 排名弱相关（Spearman ρ=0.14），HunyuanVideo 1.5-I2V 视频质量最高但 H2RCore 仅 30.0/30.7；Mitty-EPIC14B 视频质量最低但 H2RCore 仍达 61.5/56.1。
  - 灵巧手形态整体优于平行夹爪：9/11模型 H2RCore 提升均值 +3.3分；接触转移提升 +0.055，形态正确性提升 +0.047。
  - 参考图像干预效果模型依赖：Wan2.7 显著提升（夹爪 +6.6分），但 Kling-V3 和 Seedance 2.0 反而下降。
  - 视频条件 vs 帧条件：三视频条件模型占据领先，九帧替代完整视频的 ablation 导致 H2RCore 下降 27.6（夹爪）/ 41.4（灵巧手）。
  - 人机一致性：三位人工评审与三 MLLM 评委的聚合评分 Spearman ρ=0.883，传递子分数 Pearson r=0.930。

## 相关工作脉络
1. **VBench / T2V-Bench / EvalCrafter**：通用视频生成基准，评估视觉质量、时序一致性与文本-视频对齐，但未涉及机器人操作或跨形态转移，定位为低层视觉质量评测。
2. **WorldModelBench (Li et al. 2026a)**：评估视频世界模型的物理常识与动作完整性，但仍基于文本或机器人-centric 初始状态，不评估从人类示范的源条件化转移。
3. **RBench / RoboWM-Bench / RoboTrustBench**：机器人视频评测基准，关注执行性、物理合理性与可信度，但缺乏源视频条件与跨形态对比设计，无法诊断"人类→机器人"特有的失败模式。
4. **Mitty / H2R-Grounder / Human2Robot**：已有从人类视频生成机器人视频的方法，本文工作为这些方法提供系统化评测框架，定位差异在于基准覆盖的转移维度更全面（目标、动作、接触、形态四维度联合诊断）。
5. **EgoDex / Ego4D / Open X-Embodiment**：操作数据集与基准，本文借用 EgoDex test split 作为源视频来源，但评测重点从"学习策略"转向"视频生成的跨形态保真度"。

## 局限性与未来方向
- **仅评估视觉可见的操作转移**，不验证物理可执行性或下游策略性能，生成视频的真实机器人可用性仍需后续验证。
- **数据规模与形态覆盖有限**：120个源视频仅覆盖部分操作变化，且仅测试两种形态（平行夹爪、灵巧手），未涵盖软体机器人、轮式移动平台等多样形态。
- **仅评估短视频片段**，扩展至长程操作演示需引入高效时空建模。
- **原生接口对比混杂了模型能力与条件化接口差异**（视频条件 vs 帧条件模型不可直接对比）。
- **遮挡、细微接触与严重生成伪影下**，即使多评委聚合仍可能存在不确定性，未来可结合密集视觉定位（如参考文中引用的 SaFiRe、AttrSeg 等工作）与3D重建增强诊断能力。
- **未来方向**：引入长视频评估、更多形态变体、几何感知的视图合成、细粒度3D对象重建用于对象几何诊断。

## 研究启发与可借鉴点
1. **多维度评估框架的可迁移价值**：目标-动作-接触-形态分离评估的设计可直接复用于其他跨模态/跨形态生成任务（如人类到动物、虚拟到真实的动作生成），避免单一质量指标掩盖真实能力缺陷。
2. **源-评标注分离的协议设计**：结构化标注仅用于评分、不参与生成提示词，确保评测对源操作的忠实度不受提示词泄露影响，此设计值得推广至所有源条件化生成基准。
3. **灵巧手 vs 平行夹爪的性能差异启示**：更贴近人手的形态显著改善接触转移与形态正确性，提示**形态相似度是影响跨形态转移的关键因素**，可为后续机器人形态选择与合成数据生成提供指导。
4. **参考图像的模型依赖效应**：同一参考图像对 Wan2.7 有益、对 Seedance/Kling 有害，揭示**不同架构对条件化输入的敏感性差异**，提示未来工作需针对模型特性定制参考条件策略。
5. **视频质量与转移能力的解耦发现**：HunyuanVideo 1.5 高质量但低转移能力，Mitty-EPIC 低质量但相对较高转移能力，表明**视觉质量优化与操作保真度优化可能是正交目标**，需分别建模与评估。

## 关键术语表
**H2R-Bench**：人类到机器人操作视频转移基准测试，评估视频生成模型在第一人称人类示范视频条件下生成指定机器人形态操作视频的能力。
**EgoDex**：大规模第一人称灵巧操作视频数据集，本文作为源视频来源，提供丰富的手-物交互与状态变化证据。
**H2RCore**：五维评估指标的加权聚合得分，权重为0.15(目标)+0.15(动作)+0.30(接触)+0.30(形态)+0.10(质量)，范围0–100。
**功能接触转移（M3）**：评估生成视频中机器人建立的操作交互是否与源视频中的手-物接触在功能上等效，包括接触区域、操作模式、对象响应与形态兼容性。
**身体形态正确性（M4）**：评估生成视频中机器人外观的一致性，包括机器人存在、人类手部消失、形态类别匹配、末端执行器正确与结构时序一致。
**源条件化（Source-conditioned）**：生成模型以特定源视频为视觉条件，而非仅依赖文本或随机初始化，要求输出忠实保留源证据。
**跨形态转移（Cross-embodiment transfer）**：将人类示范的操作意图、动作序列与交互证据从一种身体形态（人手）迁移到另一种形态（机器人末端执行器）的过程。
**结构化标注（Structured annotation）**：由多模态语言模型生成的包含任务目标、动作事件、接触证据与形态策略的JSON格式描述，经人工验证后用于自动化评分。

## 可复现要素
- **数据集**：使用 EgoDex test split（公开数据集），120个源视频；基准实例（240个转移案例+结构化标注）项目页面：https://rongdingyi.github.io/H2R-Bench/，论文未明确说明代码/基准是否开源仓库地址。
- **代码/权重**：论文未明确提供开源代码仓库链接；模型生成使用各模型官方API（Seedance 2.0、Wan2.7、Kling-V3等）或本地部署（LTX-2.3、Mitty-EPIC14B、SkyReels-V3、LongCat、Wan2.2、HunyuanVideo 1.5）。
- **关键超参**：MLLM评委温度=0；每视频采样25帧用于M1–M4；M5使用完整解码视频；六类操作任务各20个源视频；目标形态为平行夹爪与灵巧手各一种。
